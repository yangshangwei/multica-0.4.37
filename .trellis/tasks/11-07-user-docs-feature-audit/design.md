# 文档设计

沿用 MDX → 中文文档生成器 → Go 内置 JSON → 使用文档阅读器的既有链路。新增指南拆为功能总览、协作空间、协作上下文与知识、MCP 与市场、统计与用量，审批操作补入智能体页；核心概念与首页负责导览，其余在现有页面中修正。

按功能分配互不重叠的 MDX 文件，所有生成操作由主会话串行完成。源码与翻译标签共同作为行为证据，测试作为权限/限制依据，旧计划只作查找线索。记录覆盖矩阵供独立复核。新增页面都登记 meta.zh.json，不改路由实现或产品深链常量。

目录/正文保留既有稳定链接；如标题更名影响锚点，同步检查引用。服务器升级后才会提供新文档，桌面包版本不等同于文档版本。
