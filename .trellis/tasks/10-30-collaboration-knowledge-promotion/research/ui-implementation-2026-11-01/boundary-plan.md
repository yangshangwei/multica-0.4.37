# Shared knowledge UI boundary

Operate mode extends the current collaboration panel, project description area and workspace settings. The approved purpose/roles are fixed. Main ran Impeccable context once; incumbent source/controls define the visual system. No global redesign, routes, new dependencies, AI summaries or assets.

New shared collaboration components own source/target collections, live candidate review/actions, client proposal forms and source selection. Narrow mount points are `collaboration-detail.tsx`, `projects/components/project-detail.tsx`, and `settings/components/workspace-tab.tsx`; localized copy lives in both collaboration locale files. Core may add a source-reference builder and tests, using existing exact-version readers and SHA-256 of their canonical text. No Go/daemon/router files or commits.

Source selection covers memory, comments and run records independently. A selected version remains pinned when latest advances; memory history/comment history recover lawful old versions. Source workspace/current project are taken only from the authorized issue; other target catalogs mount only for normally visible workspaces. No source membership is invented and no private directory is queried for external handlers.

Query owns all candidate/source server data. Local state holds selection IDs, user-written form input and immutable intent/recovery identity. Correction/derivation starts a blank human-written proposal against the selected predecessor, avoiding a retained copy of private server body in form state. Approval is tied to the live displayed full candidate and exact state/version/hash. Losing that projection resets confirmation and removes old content. Source-unavailable rejection and restricted target-only withdrawal retain their distinct boundaries.

Actions await exact receipts; known refusal has error feedback, uncertain results retain original bytes/key and expose GET recovery/retry. Recovery identities survive reload without private payload persistence. Unsupported routes display their limited state within the section and do not break surrounding pages or claim an empty collection. Core leases and all-version paging remain authoritative.

Verification: focused Node source-builder tests, shared interaction/keyboard/permission/privacy/recovery tests, locale parity, Core/Views typecheck and scoped lint. Main owns production Web/native Desktop setup, mechanical detector and independent screenshot review. Evidence/hashes are retained in this directory; UI tests do not claim G2 injection or model understanding.
