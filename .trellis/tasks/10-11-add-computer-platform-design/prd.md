# 添加电脑：三系统连接引导实现

## Goal
在现有设计基础上实现 Web/Desktop 共用的添加电脑弹窗，让用户为目标电脑选择正确系统、复制可用安装和连接指令，并看到真实的新电脑连接结果。

## Confirmed scope
- 2026-10-11 用户已批准原静态设计；本轮明确回复「按现有设计推进功能实现」。复用现有任务，无需创建重复任务。
- 已有 Windows/macOS/Linux、地址异常、无浏览器登录和成功态图稿，见 docs/design/2026-10-11-add-computer/。
- 当前共享弹窗只有 Bash 安装命令，任意 daemon:register 都切换成功；配置只有一个 cli_install_command。

## Requirements
- R1：首次不预选目标系统；Windows 使用 PowerShell，macOS/Linux 使用终端；有 WSL 和系统账号提示。
- R2：保留两步安装/登录连接流程，支持每系统自托管安装来源；旧单一安装命令仅保留 Unix 路径；配置了内网来源但缺少目标系统时不回退公网。
- R3：拒绝回环、未指定及无效或不完整的服务地址；保留安装步骤和现有本地文档入口，不猜 IP 或修改部署。
- R4：复制显示成功/失败文本、长命令可完整选取复制；切换系统清除复制反馈；无浏览器的配置、交互令牌登录、daemon start 分开复制。
- R5：真实数据确认新增电脑后显示名称、实际系统、可用运行时；已有电脑重连、畸形通知不得触发成功；等待、迟迟未连接、页面连接中断可区分并恢复。
- R6：遵循共享组件、语义 token、中英文、键盘/焦点/滚动和 reduced-motion 约定；Web/Desktop 行为一致。

## Acceptance criteria
- [x] AC1 / R1：三系统命令正确、初始无命令、切换和重开状态正确。
- [x] AC2 / R2：配置后端→schema→store→弹窗完整；旧响应、畸形字段、内网缺项有回归覆盖。
- [x] AC3 / R3：回环/无效/部分地址不展示连接或 token 配置命令；有效地址安全引用并完整复制。
- [x] AC4 / R4：复制成功/失败/切换、无浏览器三段执行有行为测试。
- [x] AC5 / R5：新增真实电脑显示成功；旧电脑重连、未知 payload、断线/重试保持准确状态。
- [x] AC6 / R6：相关 tests、lint、typecheck、Go config 测试通过；浏览器检查主状态和窄窗口，记录验证边界。

## Out of scope
不改安装器，不自动安装软件或运行真实 Agent，不做三系统真实双机验收，不改移动端/部署服务，不引入新依赖。无数据库改动。

## Deliverables
共享弹窗、按系统配置契约、部署说明、回归测试及 verification.md；原图稿保留为设计依据。
