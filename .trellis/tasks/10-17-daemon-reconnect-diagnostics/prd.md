# 细化桌面守护进程重连异常与诊断步骤

## Goal

Windows 桌面端在"设置 → 守护进程 → 重新连接此设备"失败时，应明确显示失败环节、原因类别和初步排查步骤，帮助用户区分 CLI 不可用与设备注册校验失败。

## Background and confirmed facts

- 用户报告重连时提示 `Installation challenge does not match the current scope`，运行状态为"安装失败"；尚未取得该 Windows 设备的运行证据。
- `apps/desktop/src/main/managed-installation.ts:214` 的挑战校验在第 240 行合并抛出身份范围、请求完整性和时间有效性异常，现有错误无法区分触发条件。
- `apps/desktop/src/main/daemon-manager.ts:1519` 的 `bootstrapCli` 仅在找不到可用 CLI 时设置 `cli_not_found`；注册校验异常不会直接设置该状态，两种异常可能并存。
- `apps/desktop/src/renderer/src/platform/daemon-reauth.ts:27` 使用英文 toast 展示原始错误；`apps/desktop/src/renderer/src/components/daemon-settings-tab.tsx:225` 的诊断区未显示具体失败原因。
- 用现有 Node/Go 签名 fixture 执行验证，确认时钟偏差能触发同一错误；不能据此认定用户设备的根因。详见 `research/findings.md`。

## Requirements

### R1：细分设备注册异常

区分挑战过期、超出允许时间范围、身份范围不匹配、响应格式或完整性异常。显示本地化的失败环节、原因及安全的差异字段名称，例如账号、部署、工作空间或设备绑定；不展示原始挑战值。

### R2：保留并区分安装与重连异常

CLI 安装/执行验证失败与设备注册/凭据/重启失败独立显示。如果两者并存，运行状态保持真实，各自原因可查看。toast 消失、状态轮询和同一应用会话内离开再进入设置后，仍可查看未解决异常。对应操作成功后清除对应异常；账号/服务器切换清除旧连接诊断，过期请求不得污染新上下文。

### R3：提供对应的初步诊断步骤

- 时间异常：检查 Windows 日期与时间、自动时间同步，重新连接获取新挑战；持续失败时检查服务器时间。
- 范围异常：确认当前服务器、账号及切换已完成，重试后仍失败则携带安全的错误类别和字段名反馈。
- CLI 异常：根据已观测阶段区分下载、校验、解压/写入和可执行文件验证失败，给出网络/代理、Windows 防护历史、架构或权限检查建议，不臆测原因。
- 其他异常：保留失败环节及安全 HTTP 状态等信息，提供重试/反馈建议，未知原因使用明确的通用说明。

### R4：中英文与可用性

在设置诊断区显示持续可见的摘要和有序步骤，重连 toast 改为简短本地化反馈。保持已有忙碌、外部管理和登录限制；长文本可换行，窄窗口仍可操作。复用现有组件与翻译资源。

### R5：保留身份安全和恢复语义

所有现有校验仍拒绝同样的无效输入，成功签名的字节不变。不放宽 TTL、不绕过身份校验、不降级旧鉴权、不删除身份数据；只有现有明确会话失效才退出登录。诊断信息不包含私钥、PAT/JWT/MDT、metadata proof、nonce、签名/请求载荷、原始响应或任意异常文本。

## Acceptance Criteria

- AC1（R1/R3）：过期、超前时间窗口、账号/部署/绑定不匹配、格式与完整性异常可区分，匹配对应中英文步骤。
- AC2（R2）：`cli_not_found` 后再发生挑战错误，可同时查看两者，轮询或重进设置不丢失。
- AC3（R2）：成功仅清除对应错误；账号/服务器切换及旧请求回调不会展示旧连接诊断。
- AC4（R4）：中英文摘要和步骤完整、长文本换行、原有操作限制保持，未知错误有安全回退。
- AC5（R5）：原签名 fixture 不变，无效挑战仍拒绝；瞬时失败保留登录，诊断不泄露凭据。
- AC6：相关回归、桌面端 typecheck/lint 通过，明确说明是否验证过原生 Windows 与真实服务器。

## Out of scope

服务端协议修改、身份重置/迁移、自动调整时钟、禁用 Windows 安全软件、设置页整体重设计、通用遥测系统、打包发布部署，以及在没有实际设备证据时宣称修复了该 Windows 环境。

## Planning status

用户已于 2026-10-17 同意创建任务并进入规划，并在最终规划摘要之后明确回复"请开始实施"。实现、独立复核与最终验证已完成，结果见 `verification.md`。原生 Windows、用户现场服务器与安装包发布不在本次已验证范围内。
