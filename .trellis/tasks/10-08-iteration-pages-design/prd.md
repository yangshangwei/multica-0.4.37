# 迭代业务页：时间线总览与详情设计

状态：实施收尾中；用户已于 2026-10-09 授权按父任务 [closeout-plan.md](../10-08-iteration-workspace-settings/closeout-plan.md) 完成修复、验证、提交和归档。此前的规划状态由该授权取代。

## 目标与依据

让成员一眼了解下一阶段的计划、当前进展和过去结果，再进入某个迭代安排任务或复盘。参考用户提供的两张界面：总览采用宽松的纵向时间线、未来周期、间隔、展开的当前图表及右侧统计；计划详情采用左对齐标题和添加／新建任务入口，保留大面积留白。

已有 I1 支持手动周期、按任务数统计、完整操作预览和冻结历史。列表只返回周期元数据，详情才有统计；图表只包含有效范围、已完成、原始承诺三个序列。日期经过不会自动切换状态，同时最多一个进行中周期。

## 需求

| 编号 | 要求 |
| --- | --- |
| IP-01 | 保留现有总览和详情地址。总览分为“当前与计划”和“历史迭代”两个标签；计划从较晚到较早排列在当前上方，历史标签内从较近到较远排列。点击周期进入对应详情。 |
| IP-02 | 当前周期默认展开进展图和右侧关键任务数；计划和历史使用紧凑行，只展示名称、日期、状态等已有元数据。没有当前周期时明确显示“暂无进行中的迭代”，不把最近计划视为已开始。 |
| IP-03 | 时间线可显示确定的未安排日期间隔，准确标注天数；筛选、缺页、重叠或无法比较时不推断间隔。“未安排”不代表冷却期或自动排期。 |
| IP-04 | 保留名称搜索、日期范围和状态筛选，并提供清除筛选及无结果反馈。筛选不改变全局当前／即将开始身份，不能让未加载的周期消失于假定完整的时间线。 |
| IP-05 | 详情标题区展示名称、日期、周期保存的时区、状态及协调人，保留返回和复制链接。任务、进展、范围变化分别放在标签页中；编辑与生命周期操作使用清楚的按钮或菜单入口。 |
| IP-06 | 未分配任务的计划详情默认展示左对齐空状态，主操作“添加已有任务”，次操作“新建任务”。只有已确认为空才展示此状态；已有任务但筛选无结果时提供清除筛选。新建使用现有手动创建能力，默认选中本周期并明确显示归属。 |
| IP-07 | 任务页保留当前／原始范围、搜索、状态／项目／负责人／优先级／标签筛选和分组、分页及结转提示。周期整体统计不随任务筛选变化。 |
| IP-08 | 进展按任务数展示有效范围、已完成、剩余及现有完成率；图中原始承诺使用虚线，不绘制执行中序列、预测线或未来补值。零分母展示“不适用”，数据失败不显示零。完整统计和可访问数据表仍可查看。 |
| IP-09 | 完成或取消详情显式标记历史已冻结，使用冻结的任务事实、统计、事件、结束原因与结转去向。现时任务对比仍可按需查看，但不得覆盖历史。允许的名称／说明更正遵守现有规则。 |
| IP-10 | 沿用人类成员的周期维护权限、任务分配权限、完整预览确认、修订冲突和原请求恢复。开始、结束、取消及明确选择的交接均是手动操作；页面布局变化不新增自动执行行为。 |
| IP-11 | 业务页不放启用开关、规划时区设置或默认周期配置。启用／不支持／禁用后的历史访问遵守当前能力接口；与父任务设置集成时沿用其 gate 及历史入口，不能出现第二套设置控件或失效链接。 |
| IP-12 | Web 与桌面共享业务视图；支持中文、英文、深色、窄桌面窗口、键盘及屏幕阅读器。暂时刷新失败保留可访问旧数据和编辑草稿，撤权立即清除受保护数据。 |

## 验收标准

| 编号 | 可观察结果 | 对应需求 |
| --- | --- | --- |
| AC-01 | 总览中较晚计划在较早计划上方；当前仅一条且默认展开；切到历史标签后较新记录在上。点击三类行分别打开当前、计划、冻结历史详情，原有直达链接仍有效。 | IP-01,02 |
| AC-02 | 10 月 1–7 日与 10 月 10–16 日之间显示“2 天未安排”；相邻、重叠、同日期、跨时区、缺页或筛选状态不误报间隔。不会生成冷却期设置。 | IP-03 |
| AC-03 | 超过一个 API 分页的周期仍按正确顺序显示；当前不会因位于后续页而被漏掉。失败提供重试；无周期与筛选无结果有不同反馈。 | IP-02,04 |
| AC-04 | 总览只对展开的当前周期请求统计，未来／历史行不逐行加载详情。图的每个已绘制日期及数值均来自响应，表格与图一致。 | IP-02,08 |
| AC-05 | 计划详情空状态符合参考图的左对齐和留白；添加可选择并确认现有任务，新建可确认本周期归属。成功后出现任务；取消、失败或结果未知不伪装成成功。 | IP-05,06,10 |
| AC-06 | 三个详情标签页可由键盘切换；任务筛选与分组仍有效，任务筛选不改图表；切换标签不丢失当前筛选、编辑草稿或待恢复操作。 | IP-05,07,12 |
| AC-07 | 已完成、有效范围、剩余均为任务数；零分母显示不适用；统计失败显示错误或带提示的上次成功值，不显示 0%。 | IP-08 |
| AC-08 | 当前任务后来改名、换负责人或重开，历史表格、曲线及冻结完成率保持原样；历史对比入口明确区分当前值；名称／说明更正不重算快照。 | IP-09 |
| AC-09 | 普通人类成员保留维护周期的既有权限；机器凭据不会因新按钮获得权限。冲突须重新确认，响应丢失沿原身份恢复；状态已变化或功能已关闭也仍能恢复。 | IP-10,12 |
| AC-10 | 未启用及旧服务状态不展示写入口，已关闭仍可读历史；未知状态／模式只读且有说明。与父设置页集成后可从业务页到真实设置入口，再回到历史。 | IP-11,12 |
| AC-11 | 中文／英文、1440px 与 900px 桌面窗口、深浅色中无横向页面溢出；图右侧统计可换行；按钮、标签页、对话框有焦点反馈，图表可通过数据表理解。 | IP-12 |

## 范围与交付

交付总览、当前详情、计划空详情、冻结历史详情的交互原型与本套规划文档。主会话负责原型；示例周期和图表均为演示数据，不连接真实后端。生产实施遵循 [design.md](design.md) 与 [implement.md](implement.md)。

不新增自动排期、自动开始／结束／下一周期、默认冷却期、容量／分钟／估算单位、执行中历史曲线、批量统计 API、数据库结构、依赖或移动端界面。保留既有明确交接能力，但不把它包装成自动推进。设置页及父任务的已有预览由父任务维护。

本子任务方案已获用户批准，已进入产品实现与收尾；父任务负责设置集成与跨子任务验收，执行依据为父任务 closeout-plan.md。
