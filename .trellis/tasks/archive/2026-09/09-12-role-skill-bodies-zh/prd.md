# 将七个内置角色 skill 正文中文化

## Goal

将七个内置角色 skill 的正文改成准确、自然的简体中文，并让用户当前工作区的对应副本生效。

## Requirements

- 七个 skill 的规则、职责、证据要求和审批边界保持原有语义。
- 原 frontmatter、调用名称、命令、参数、路径、状态值和绑定保持稳定。
- 中文业务术语遵循项目规范；不强制改变所有智能体的输出语言。
- 保留现有工作区个性化内容；中文化不得隐式升级旧版业务规则。
- 不新增依赖、数据库迁移或全工作区自动覆盖逻辑。
- 更新前可备份，更新后可核验，发生冲突时不覆盖其他修改。

## Acceptance Criteria

- [x] 七份源码正文为简体中文，frontmatter 与原版本一致。
- [x] 独立审查确认关键规则和程序标识未丢失或改变。
- [x] 既有物化、定制保护、复用、CLI 输入、显示层与下发相关检查通过。
- [x] 目标工作区七份正文已更新并读回核对，或记录无法完成的精确阻塞及已完成部分。
- [x] 身份、metadata、标签、绑定和附属文件保持原有值。
- [x] 技术方案、执行记录、备份位置和验证结果可供复核。

## Authorization

用户于 2026-09-12 明确要求“请制定修改为中文的技术方案，并执行”，包含方案和实施授权。
