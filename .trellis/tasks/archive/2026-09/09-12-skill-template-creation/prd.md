# 从模板中修改并创建 skill

## Goal

让用户在新建 skill 时从现成模板开始，修改后创建独立的工作区 skill。

## Scope

用户已要求推进执行，首版按已审阅方案使用七个内置角色模板。

## Requirements

- 新建方式中增加“从模板中修改”，沿用现有产品视觉风格。
- 可选择模板、预览中文正文、编辑名称和描述及正文，然后创建副本。
- 提交前不创建数据库记录，取消不产生垃圾 skill。
- 副本独立可编辑，不影响原模板、原工作区 skill 或智能体权限与绑定。
- 保留草稿，明确处理返回、关闭、换模板、重名、失败和语言/工作区变化。
- 创建等待有上限；超时或无法确认结果时恢复操作，不自动重复创建或进入身份不明的详情页。
- 名称与描述在数据库和 SKILL.md 中保持一致，其他模板字段保持其类型和值。
- 首版支持 Web 和 Desktop，不引入模板管理系统、市场、自动更新或 AI 改写。

## Acceptance Criteria

- [x] 五种创建方式均可见、可操作，矮窗口不会裁切底部入口。
- [x] 空工作区能浏览七个内置模板，预览和取消不会新建 skill。
- [x] 编辑后的副本获得独立身份，原模板和现有 skill 不变。
- [x] 返回保留草稿，切换模板及关闭在有手工修改时才要求放弃确认。
- [x] 409、网络失败和请求中的重复操作不会丢草稿或静默覆盖数据。
- [x] 数据库名称/描述与 frontmatter 一致，正文与附属文件按编辑内容保存。
- [x] 中文界面、语言切换、Web/Desktop 导航及小屏/键盘操作正确。
- [x] 新旧客户端/后端组合能明确处理功能不可用，既有四种方式不受影响。
