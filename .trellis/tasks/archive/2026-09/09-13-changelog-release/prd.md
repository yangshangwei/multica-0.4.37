# 从提交记录生成并发布变更日志

父需求：[`09-12-desktop-changelog`](../09-12-desktop-changelog/prd.md)。用户已要求完成设计、实现和验收。

## 验收标准

- [x] 从选定的不可变提交范围生成分类 Markdown 和累计 JSON。
- [x] 只把真正发布的标签标记为发布；工作区未提交内容不会进入正式日志。
- [x] 重复生成相同版本幂等；保留历史；错误基线、版本冲突和损坏历史会阻止发布。
- [x] 发版构建和最终发布使用同一份已验证日志；失败构建不会宣布成功发布。
- [x] 支持内网或离线包携带日志，以及原子发布到服务端挂载目录。
