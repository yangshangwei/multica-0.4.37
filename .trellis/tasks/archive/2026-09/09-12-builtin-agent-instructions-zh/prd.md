# 内置智能体指令中文维护方案

## 目标

让中文团队能用中文阅读、修改、保存和维护内置智能体指令，并保持团队已有定制及角色职责。源码、工具及指定工作区的实例转换均已完成。

## 需求

- 覆盖 Mika、8 个工作角色、8 个小队负责人及 8 个小队公共指令。
- 编辑界面中的正文与保存后实际执行的正文一致。
- 使用简体中文产品术语，保留机器可识别的 key、CLI、字段、状态、风险类别及占位符。
- 同时考虑新建与已有实例；历史指令的中文化不得顺便升级行为。
- 切换个人 UI 语言不改变团队共同维护的指令或本地未保存草稿。
- Mika 维持产品段只读、团队补充可编辑，发布不能覆盖补充。
- 保留自主权限、审批、小队路由与父任务状态规则。
- 7 个已有中文正文的角色 skill 无需重译。
