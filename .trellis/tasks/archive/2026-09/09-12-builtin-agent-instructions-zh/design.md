# 技术设计

完整设计与方案比较维护在 `docs/plans/2026-09-12-builtin-agent-instructions-zh.md`，其中“推荐设计”“方案比较”“现状与原因”为本任务的设计依据。

核心决策：当前中文团队部署采用单份中文正式正文，沿用现有 `instructions` 保存与运行链路。新模板翻译、Mika 系统段更新和旧实例转换分别处理。多语言工作区支持是另一种方案，不能靠个人 UI 语言隐式修改共享正文。

边界：Mika 产品段只读、工作区补充可写；普通角色与小队在创建时复制，之后正文归工作区维护。模板来源版本不能证明正文未被修改。

兼容：保持字段与权限契约；纯正文翻译不新增数据库字段或依赖。旧内容转换依据历史正文完整匹配，使用工作区限定和原正文/更新时间条件更新；通知和缓存行为遵循现有正常更新路径。回滚同样采用条件检查。

完整运行 prompt 包含额外的平台规范和上下文，当前编辑框只承担可维护角色正文；完整动态预览不纳入第一阶段。
