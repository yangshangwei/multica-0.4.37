# 将内置协作助手 Mika 统一更名为小阿孚

## Goal

统一内置协作助手的默认名称、界面文案、系统指令和旧默认实例，保持 mika 系统身份、现有接口和用户自定义内容兼容。

## Requirements

- R1：本部署新建内置助手默认名统一为「小阿孚」，中英文入口使用同一名称。
- R2：更新引导页、运行时提示、默认会话标题、安装引导任务和可见错误，覆盖共享 Web/桌面端。
- R3：系统提示与内置引导 skill 使用当前显示名称或名称无关的角色描述，继续支持用户改名。
- R4：有条件更新已有内置助手的旧默认名称、默认简介和默认引导会话标题；保留自定义名称、简介、指令、标题与历史消息。
- R5：同工作区有目标名称冲突时保留原记录并报告；其他工作区继续更新。重复迁移不产生额外修改。
- R6：保留系统身份、接口、UUID、任务分配、提及、会话复用及已保存自动化/小队关联。
- R7：完成必要回归，记录迁移恢复、旧客户端和按名称调用脚本的注意事项。

## Acceptance Criteria

- [x] 新工作区中英文创建均得到名为「小阿孚」的内置助手，重复创建复用原实例。
- [x] 产品当前入口的固定助手称呼一致；当前名称进入系统提示与新开场白。
- [x] 迁移更新旧默认实例，同时保留普通同名智能体、用户定制及历史正文。
- [x] 活动或归档的同名记录触发冲突报告，不覆盖其他智能体或阻断无冲突工作区。
- [x] 迁移重复执行稳定，代码回滚保留用户内容，跳过冲突后的恢复方式有说明。
- [x] 相关 Go/TypeScript 测试、类型检查、lint 和迁移静态检查通过。
- [x] 本次修改合回原目录时保留技能市场等其他任务的未提交工作。

## Background and authorization

用户在收到更名范围、兼容方案、存量和冲突风险评估后，明确要求「请新建 trellis 任务，将 Mika 统一修改为 小阿孚」。本任务落实该方案；无待确认的产品决策。

- 显示名与系统身份分离：`server/internal/service/builtin_agents.go:16`。
- 创建流程复用旧实例：`server/internal/handler/mika_agent.go:120`。
- 共享前端核心涉及 7 个文件、35 个字符串；移动端按服务端名称显示。
