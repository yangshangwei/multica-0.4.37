# 快速创建任务：智能体选择器优化（第一期）

## 目标与授权

让拥有大量智能体的用户在“通过智能体创建”时，快速找回常用对象，也能根据职责找到不熟悉的智能体或AI小队。

用户于 2026-09-29 接受第一期推荐，要求形成需求设计、技术方案和 Trellis 任务。当前交付为规划文档；本文件中的具体交互细则是对已接受范围的设计细化，供实施依据与评审使用。

## 背景与证据

- 用户截图：[当前选择器](research/current-picker.png)。名称平铺，智能体多时需要长距离滚动，职责差异不容易判断。
- `packages/views/modals/quick-create-issue.tsx:976`：ActorPicker 仅显示名称，名称/拼音搜索，智能体组排在小队组之前。
- `packages/views/modals/quick-create-issue.tsx:221`：已有显式传入、草稿、上次成功提交、首个可用智能体的预选顺序。
- `packages/views/modals/quick-create-issue.tsx:657`：小队选择交给队长运行创建流程；“创建对象”不等同于最终任务负责人。
- 代码调研及约束分别记录在 [偏好与隔离](research/preferences.md) 和 [交互与组件](research/interaction.md)。文件行号为规划时快照，实施前按符号复核。

## 范围

| 包含 | 不包含 |
| --- | --- |
| Web／桌面端共享的快速创建对象选择器 | 移动端、手动创建负责人、聊天、自动化等其他选择器 |

## 需求

### R1 — 常用与最近优先

打开选择器后，若存在匹配当前可用目录的常用或历史记录，显示快捷视图：我的常用最多 3 个，最近使用最多 5 个，最多 8 个候选。同一对象不重复出现在两个分组；所有已固定对象均从“最近使用”分组排除，超出前 3 个的常用通过“查看全部常用（N）”访问。没有有效常用和历史时直接展示完整目录，避免空白首页。

“浏览全部（N）”始终可达。N 只统计当前用户能选择的对象；不包含归档、无权调用或未绑定运行时的对象。常用按固定先后排序，已有常用不会因最近使用而自动换位。最近按成功提交的先后排序，重复使用只更新位置。

### R2 — 固定为常用

智能体和AI小队都可以固定／取消固定。操作即时生效，不选中对象、不关闭选择器、不提交任务。行主操作和固定操作具有独立点击区域与键盘入口。超出快捷视图数量的常用必须有完整访问入口，不静默丢弃。

常用属于此选择器的个人本地偏好；与聊天置顶及侧边栏收藏独立。正常刷新／重启后恢复，同一工作区内生效，不承诺 Web 与桌面或其他设备同步。沿用现有退出登录清理规则，不将上一个账号的偏好展示给后一个账号。

### R3 — 最近使用的真实含义

只有创建请求被服务端成功接受，才记录一次最近使用；仅打开、选中、固定、取消、校验失败或请求失败都不记录。“最近使用”不表示后台任务已经成功完成。

保留最近 20 个去重对象供解析与快捷展示，快捷视图取其中当前可用且未固定的前 5 个。已有的“上次成功使用”默认选择继续工作；升级后可将这一条真实历史作为最近列表的初始值，不虚构更多历史。

### R4 — 可理解且真实的职责摘要

候选行显示头像、名称、对象类型和一行职责摘要。摘要来自对象已保存的 description；长内容截断展示，完整职责仍参与搜索。空描述显示“暂无职责描述”，不从名称、头像、模板名称猜测实际能力。不显示或搜索隐藏的系统指令。

AI小队使用自己的名称与描述，并明确显示“AI小队”类型，不替换成队长身份。必要时可通过补充说明显示当前可见队长，禁止据不完整成员预览生成成员关系或能力结论。

### R5 — 搜索完整目录，筛选对象类型

搜索提示为“搜索名称或职责…”。保留现有名称拼音匹配；增加对完整已保存描述的大小写不敏感包含匹配。输入前后空白忽略，纯空白等同未搜索。

无论当前在快捷、全部或全部常用视图，只要输入搜索词，都搜索完整可用目录，再与显式选择的类型筛选取交集；绝不只搜索首屏或收藏。名称精确、名称包含、名称拼音的结果优先于仅描述命中的结果。同级稳定排序，完全同名时以对象类型及 ID 打破平局。

全部／智能体／AI小队三个类型按钮始终可见，切换类型保留搜索词。搜索列表是单一结果列表，不按常用／最近重复展示。清空搜索回到输入前的浏览视图，保留本次打开期间的类型选择；关闭后再次打开恢复空搜索、全部类型、默认快捷／完整目录视图。

### R6 — 选择、状态与恢复

选择主行后只更新创建对象并关闭弹层；当前草稿、项目、上传、描述完善、版本校验和提交行为继续遵守原合同。筛选、固定、排序不能偷偷更换已选对象，也不能改动现有默认预选顺序。

权限或归档变化后的对象不出现在快捷列表、搜索结果或计数里；不根据短暂加载失败删除已存偏好。加载、请求失败和确实无结果必须可区分，失败提供重试；有缓存时保留仍可用的列表并提示刷新失败。不以“离线”额外隐藏原本允许选择的对象。

键盘可以完成搜索、切换类型、选择、固定、取消固定、浏览全部和关闭。选中状态与悬停状态可区分；中文输入法候选确认不会误选对象。固定操作导致行移动／移除时，焦点必须留在选择器内的合理位置。

### R7 — 可见性与规模

弹层提供两行信息所需宽度，受视口限制；窄屏没有横向溢出。搜索及类型筛选保持可见，列表区域滚动。全部浏览提供可继续加载的完整目录路径，不能永久截断尾部对象。

使用 500 个智能体、50 个AI小队的固定测试数据评估搜索响应及滚动。目标为已加载数据下输入到结果渲染 P95 不高于 100ms；记录浏览器、设备、构建模式和测量方法。性能目标需要实施后实测，不能以纯函数耗时或本次文档检查代替。

## 验收标准

| 编号 | 关联需求 | 可观察结果 |
| --- | --- | --- |
| AC01 | R1 | 无历史时可直接浏览；有记录时首屏候选不超过 8 个；空分组不占位 |
| AC02 | R1/R2 | 固定 4 个对象后快捷视图展示前 3 个，第四个可通过“查看全部常用”找到；常用不重复出现在最近组 |
| AC03 | R2/R6 | 点击或键盘激活固定按钮，弹层保持打开、对象选择和正文不变；取消固定后焦点不丢到页面背景 |
| AC04 | R3 | 请求被接受时才更新最近；重复使用去重并移到最前；失败和取消不记录；最多保留 20 条 |
| AC05 | R2/R3 | 刷新可恢复；切换到没有偏好的工作区不显示上个工作区数据；登出换账号不泄漏常用／历史 |
| AC06 | R3/R6 | 工作区 A 提交后切到 B，A 的延迟响应不写入 B；登出再登录时旧响应同样不写入新会话 |
| AC07 | R4 | 自定义／改名对象展示自己的保存描述；空、超长、Markdown 描述可读且布局不溢出；小队不会显示成队长 |
| AC08 | R4/R5 | 描述末尾且超出摘要截断位置的词也能命中；名称、大小写、拼音原有搜索通过；系统指令不参与搜索 |
| AC09 | R5 | 从快捷或全部常用视图搜索，能找到未固定且在目录尾部的对象；类型筛选与搜索取交集 |
| AC10 | R5/R6 | 清空／关闭／重开、切换类型、固定引起重排均不会让 Enter 误选旧索引对应的新对象 |
| AC11 | R6 | 加载失败可重试，不能伪装无结果；无权／归档对象不因曾固定而重新可见 |
| AC12 | R6 | 原有显式对象、草稿、上次使用、项目上下文、小队路由、版本与权限回归保持通过 |
| AC13 | R6/R7 | 真实组件支持输入法和键盘操作；Web／桌面宽屏及 Web 窄视口截图无溢出，选中状态在悬停下可辨 |
| AC14 | R7 | 550 个对象的尾部可访问、全量可搜索；记录性能实测及不达标时的处理结果 |
