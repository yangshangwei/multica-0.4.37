# 实施计划

1. 完成 RCA 子任务的定向测试、浏览器创建和真实模型评测，记录环境限制。
2. 增加事故学习与发布后验证 skill，接入 incident/release squad，并补充脱敏样例测试。
3. 增加 reliability-engineer 与 agent-evaluator 角色、role skill、四语文案、模板测试和职责文档。
4. 统计体验/迁移工作量；若达到阈值，加入两个专项角色，否则只加入受控 skill/路由和负向测试。
5. 增加契约兼容、威胁建模、供应链、产品结果、灾备五类能力，优先复用既有角色。
6. 更新 server template spec、本地化与用户文档，运行 Go/TypeScript/模板/浏览器检查。
7. 用一份事故样例和一份 Agent 变更样例做端到端演练，核对总任务验收标准。

每一步都保留可回滚的独立提交；不得把生产发布、线上迁移、凭据读取或外部通知放进自动化测试。
