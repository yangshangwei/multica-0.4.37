# Design
Reuse IssueDescriptionAssist and existing API {text, questions}. Completed result adopts via ContentEditor.adoptContent and synchronizes the draft. Streaming remains preview-only. Store pre-operation text for undo; guard edits, uploads and submission before auto adoption. A stale result remains available for inspection but never overwrites edits. Inline question inputs and a delegate choice capture explicit answers; merge question/answer context into live Markdown via the same adoption path, no extra AI round-trip required. Backend prompt emphasizes executable concise goals and only 0-2 blocking unknowns, no fabricated requirements. Older API clients stay compatible.
