# 工作区内置能力与项目开箱即用

## 目标与授权
用户已确认页面方案，并明确授权需求文档、技术设计、任务拆解和实施。第一版复用已有研发模板；桌面端优先，业务页面和 Web 保持一致。创建项目后可直接向默认小队发起第一条任务，保留自建和用户内容。

## 用户流程与验收
### 新工作区
- [x] 创建并选择运行环境后进入项目列表，空状态突出“创建第一个项目”。
- [x] Mika 保留现有聊天入口。未连接环境仍可创建项目，状态不得虚假显示就绪。

### 项目配置
- [x] 项目描述下方展示仓库/本地目录与执行小队。
- [x] 默认推荐特性交付，支持其他模板、可调用已有小队、不使用小队。
- [x] 创建项目同时保存资料与选择，并自动准备所需角色和 skill。
- [x] 执行环境只使用当前用户有权使用的环境；本地目录匹配对应机器。
- [x] 保留已有角色、skill、小队的修改；重复请求不重复创建。

### 第一条任务
- [x] 项目列表/看板上方展示小队与状态，提供更换、连接、重试、交给小队。
- [x] 交给小队预填普通任务弹窗的项目、小队与待办状态，沿用服务端触发预览。
- [x] 用户确认任务后才执行；创建项目和浏览模板不调用 agent。
- [x] 修改项目默认小队不重写已有任务。准备失败保留项目并可重试。

### 内置资源
- [x] 小队、智能体、skill 页标题下直接展示内置目录，空工作区也可见。
- [x] 小队可用于新项目或已有项目；角色/skill 可查看、创建副本，已有实例可打开。
- [x] 模板与实例按实际来源识别，不仅凭名称；保留自建入口和已有筛选。

### 自动化
- [x] 自动化页直接展示模板；项目详情资源下增加添加自动化。
- [x] 从项目进入预填项目和小队，展示频率、时区，用户编辑不被后续加载覆盖。
- [x] 只有“启用自动化”提交才创建规则与触发器，之后沿用暂停/恢复等操作。

## 质量约束
- [x] 旧项目和缺失/畸形 API 字段可正常读取。
- [x] 验证权限、跨工作区、重复/并发、失败回滚、删除/归档、用户修改保护。
- [x] 四个 locale 的 key 对齐；使用共享组件、设计 token 和导航适配器。
- [x] 相关 Go/TS 测试、类型检查、lint、浏览器验证通过；不执行真实 agent CLI。
- [x] 无新依赖、无数据库外键；新增索引必须 CONCURRENTLY 且单独迁移。

## 不包含
模板商店、新角色体系、默认运行全部自动化、升级覆盖用户副本、自动更改历史项目/任务、原生移动界面、生产部署。
