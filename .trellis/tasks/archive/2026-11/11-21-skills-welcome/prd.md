# Skills 首次使用欢迎页

## Goal

将 Skills 现有空目录提示设计成参考截图中的欢迎页，让用户理解如何把团队工作方法写成可复用的 `SKILL.md`，并开始创建、导入和分配 skill。

## Authorization and Review Status

- 原始请求：参考用户提供的 UI 设计 Skills 欢迎页，明确调用 impeccable。
- 2026-11-21 用户批准“创建 skills-welcome Trellis 任务并进入规划”。
- 2026-11-21 用户在审阅最终方案后明确回复“批准按此方案进入实施”；需求、设计和执行计划已获批准。

## Background and Evidence

- `packages/views/skills/components/skills-page.tsx:936` 以未筛选目录数量决定现有空状态；分类为空与无匹配结果另有分支。本次保留该展示位置，不新增欢迎页路由或已读偏好。
- 模板目录与工作空间实例分离：`packages/core/workspace/queries.ts:165` 和 `:172` 使用独立查询；`server/internal/handler/skill_template.go:26` 明确模板读取不会创建工作空间 skill。
- 现有创建器实际有五种方式：`packages/views/skills/components/create-skill-dialog.tsx:77`。截图中的四种方式需要补上已有的“从模板中修改”。
- skill 更新对后续执行生效，运行时复制是快照，见 `apps/docs/content/docs/skills.zh.mdx` 的“创建或导入 skill”和“添加到智能体”；说明不得承诺实时同步运行中的任务。
- 详细文件证据、视觉参照与复用边界见 `research/repository-findings.md`。

## Requirements

- **R1 — 展示条件：** 沿用现有完整技能库为空的位置，要求技能列表查询成功、存在实际结果数组且数量为零。加载、未发起/暂停而无结果、首次失败和空缓存刷新失败保留加载或重试界面。辅助成员、智能体和运行时数据失败不阻塞成功空目录的欢迎页。
- **R2 — 数据驱动切换：** 工作空间里有任意已保存 skill 时直接显示现有列表，包括从内置模板生成的实例。搜索或分类把有数据的列表筛至零时保留无匹配恢复操作。创建、导入或实时更新带来第一条记录后退出欢迎页；全部删除后可再次出现。“首次使用”不等于已证明没有删除历史。
- **R3 — 左侧说明与真实操作：** 使用 Skills 标识和标题“把团队的做事方法写成 skill”，以简洁文案解释 `SKILL.md` 的复用价值。主按钮“新建 skill”打开既有方式选择器；次入口“阅读文档”打开当前工作空间内的 Skills 文档。保留从模板进入能力市场的既有操作。欢迎视图只保留一个主要新建按钮。
- **R4 — 三段功能示例：** 右侧依次展示“五种方式添加”“分配给智能体”“维护一份，后续执行复用”。第一段准确涵盖手动、模板、本地文件、URL、运行时复制；第二段表达显式分配和一对多复用；第三段说明共享内容后续执行生效。场景明确标记“示例”，不创建记录、不访问真实智能体、不提供假的可点击控件。
- **R5 — 交互与可访问性：** 手动前后切换和位置选择，无自动播放；首尾禁用相应方向。隐藏场景不能进入焦点和可访问树，选中状态明确，变化有简洁状态提示。切换工作空间回到首段。支持键盘、可见焦点、触控目标和减少动态效果设置。
- **R6 — 视觉与平台：** 参考图中的宽松双栏、左侧黑色主按钮、右侧浅色点阵场景与相邻卡片淡化预览，在现有 Multica 令牌内实现。Web 与 Desktop 使用同一组件；容器变窄时上下排列，主操作在示例之前。简体中文/英文、浅色/深色均保持对比度、换行和滚动可用。

## Acceptance Criteria

- [x] **AC1 / R1:** 成功空数组显示欢迎页；加载、无数据的暂停查询、失败和失败刷新不显示欢迎页；辅助查询失败仍允许成功空目录展示。
- [x] **AC2 / R2:** 普通、导入和内置来源的已保存实例均显示原列表；分类/搜索无匹配保留恢复操作。空→非空和非空→空随 Query 数据切换。
- [x] **AC3 / R3:** 新建按钮只出现一个并打开现有方式选择器；文档与模板入口使用当前工作空间路径；取消创建后焦点回到有效触发控件。
- [x] **AC4 / R4:** 三段内容准确，五种添加方式齐全；示例没有业务写入，且不暗示自动分配、运行时文件持续同步或修改正在执行的任务。
- [x] **AC5 / R5:** 三个位置均可选择，方向按钮边界正确，非当前场景不可聚焦，切换可被辅助技术感知，工作空间切换重置位置。
- [x] **AC6 / R6:** 实际渲染的宽屏、320/390px 窄视图、英文/中文和深浅主题无页面横向溢出；卡片、标题和控件可读且能滚动到达；Desktop 实际滚动容器可操作。
- [x] **AC7 / R1–R6:** 受影响组件测试、现有列表回归、locale parity、views 类型检查与 lint、相关浏览器验证通过，保留截图、视觉评审和未覆盖范围。

## Out of Scope

- 后端 API、数据库、技能导入/分配/更新语义及创建表单重做。
- 原生移动端界面、全局色彩/字体变更、全站轮播抽象和新依赖。
- 自动打开能力市场、持久化欢迎页已读标记、自动播放和真实示例数据。
- 修改其他欢迎页或当前工作树中的无关变更。

## Known Limits

- 现有 `ApiClient.listSkills()` 对格式错误的成功响应会回退为空数组（`packages/core/api/client.ts:5778`，测试 `packages/core/api/skill-template-client.test.ts:270`）。本次 UI 无法将该回退与真正空目录区分；不扩大范围修改 API 兼容契约。
- 实施严格限于已批准的共享欢迎页范围；新的 API 兼容性要求须另行界定。
