# 简化 AI 小队页并迁移模板到能力市场

## Goal

让 AI 小队页专注于已创建的小队目录，减少顶部导航层级；将内置小队模板集中到能力市场，方便从统一入口发现并用于项目。

## Background

- 当前 AI 小队页通过「工作空间 / 模板」两个标签切换已创建小队与内置模板。
- 当前能力市场由 MCP 和 Skills 两个 URL 驱动的目录组成。
- 内置模板目录已独立为 `BuiltinSquadCatalog`，负责模板展示、已有小队匹配和「应用到项目」流程。
- 小队欢迎页及已有深链/E2E 测试会进入 `/squads?view=templates`；迁移需更新站内入口并为旧书签保留明确去向。
- Web 与 Desktop 共用 `packages/views` 中的页面。

## Requirements

1. AI 小队页不再显示用于切换「工作空间 / 模板」的页面级标签，只展示当前工作空间的小队目录及原有空态、加载、错误、筛选、排序、归档和创建行为。
2. 小队页视觉结构参考智能体目录：图标与标题在页头呈现，说明和文档入口可按现有公共集合页页头模式展示；保留已有新建入口与计数。
3. 能力市场新增 AI 小队模板类别，复用 `BuiltinSquadCatalog` 的模板查询、摘要、已有小队链接和「应用到项目」配置流程，不改变模板数据或项目设置语义。
4. 市场类型仍由 URL 持有；切换类别需保留无关 query 参数和 hash，浏览器前进/后退能恢复选择；已访问目录按现有市场模式保留挂载并正确停用隐藏面板。
5. 将 AI 小队页中现有的模板入口及测试导航更新到能力市场。旧 `/squads?view=templates` 深链重定向到市场小队模板类别，并保留无关 query 参数和 hash。
6. 更新英中本地化、市场 URL helper 与相关前端规格，保持 Web/Desktop 行为一致。

## Acceptance Criteria

- [ ] AI 小队页没有「工作空间 / 模板」标签；小队目录的创建、管理、筛选、空态与错误恢复仍可用。
- [ ] AI 小队页的页头和说明链接与智能体目录的集合页视觉模式一致，并在窄容器中不引入水平溢出。
- [ ] 能力市场存在 MCP、Skills、AI 小队模板三类目录，能通过 URL 直达、切换、后退/前进；保留无关参数与片段。
- [ ] 小队模板卡片、已有实例链接及应用到项目对话框在新入口下保持原行为；加载、失败、空目录有明确状态和重试。
- [ ] 旧 `?view=templates` 深链重定向到市场小队模板类别，并保留无关 query 参数和 hash。
- [ ] 英文和简体中文的可见标签及无障碍名称一致完整；Web 与 Desktop 共用实现。
- [ ] 相关组件/页面测试、类型检查和 lint 通过；必要时更新生产 Web 路由测试。

## Out of Scope

- 不改变小队模板的服务端来源、权限、内容或项目绑定逻辑。
- 不改变 MCP、Skills 管理页与各自市场目录的业务行为。
- 不重做小队详情页、模板创建流程或智能体目录。
- 不为移除旧小队模板页签而增加新的通用目录框架。

## Key Decision

- 用户确认保留旧 `/squads?view=templates` 书签兼容：重定向到能力市场小队模板类别，并保留无关 query 参数和 hash。
- 新市场类别的 URL 值采用 `type=squad-templates`；缺失或未知类型仍默认 MCP。
