# 当前功能与内置使用文档校对

## 目标
让用户从帮助菜单的“使用文档”找到当前系统已实现功能的入口、操作步骤、权限及限制。

## 已确认背景
- 使用文档由当前服务器提供，源为 apps/docs/content/docs 的中文 MDX，生成到 server/internal/docs/content 并嵌入服务端。
- 协作空间已实现账号级跨工作空间协作，但目录尚无对应指南；MCP、市场和统计也缺少独立操作说明。
- 现有文档部分沿用 Issue、小队等旧名称，且有“全部工作都在同一工作空间”等过时范围说明。
- 本工作区有大量既有修改；核对以当前代码为准，不视为已发布到截图中的安装版本。

## 需求
R1. 核对主导航、协作空间、任务与项目/迭代、智能体/AI小队、资源、运行时、自动化、账号及管理入口，记录代码证据和文档覆盖。
R2. 按已实现能力补齐重点缺失指南，说明入口、前置条件、日常操作、权限、状态和常见问题。
R3. 修正与当前实现冲突的说明，维持任务 issue 与执行 task 的区分；保留 CLI/API 字面标识符。
R4. 补充首页导航和目录，生成内置文档包；保留深链和受保护锚点。

## 验收
- 各主功能模块在覆盖报告中有文档去向与实现证据。
- 协作空间、MCP/市场、统计等缺漏能从内置目录访问。
- 新说明不把计划或受限实现描述为通用可用能力，不引入必需公网依赖。
- 生成器、文档测试、类型检查、MDX 构建和 Go 嵌入检查通过；校验内部链接/图片/锚点与生成包一致性。

## 范围
仅中文使用文档、必要导航、生成内容和审计/任务记录。产品代码、部署、发布、版本号及用户已有改动不在修改范围。无需新增依赖或新业务功能。
