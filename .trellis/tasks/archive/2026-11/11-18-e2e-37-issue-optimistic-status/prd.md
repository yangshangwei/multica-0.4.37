# #37 普通事项：即时显示状态，失败后还原

入口：`e2e/issue-mutation-branches.spec.ts:152`。原测试从 UUID 打开一个普通 Todo 事项。第一笔 PUT 的 `status` 正确，但在模拟响应放行前，看不到详情的 `In Progress` 按钮。故障发生在回滚之前；不据此认定后端写错或重试失败。

**验收**（同一工作区、同一普通事项；UUID 打开再规范化，以及直接打开可读编号）：

- 选择 `In Progress` 只发一笔对该 UUID 的 PUT。它仍待响应时，选项列表已关闭，详情状态就显示 `In Progress`；独立 API 回读仍为 `todo`。较早开始的旧详情读取不能把此时的按钮变回 `Todo`。
- 放行首笔请求返回 503：显示失败提示，详情与服务器均为 `Todo`。一次显式重试走真实写入；服务器回读 `in_progress`，刷新仍显示 `In Progress`，全程恰好两笔 PUT。
- 正常状态编辑继续乐观更新；有完成绑定的事项仍须经过现有授权、以前台权威结果确认完成，不能在等待授权/回执时显示已完成。

范围不含更改状态目录、服务端写入协议、权限规则、协作事项或批量更新流程。沿用[父任务的运行与保留约束](../11-18-e2e-1118-followup/implement.md)。
