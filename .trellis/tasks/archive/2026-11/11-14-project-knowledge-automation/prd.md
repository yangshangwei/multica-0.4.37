## Goal

让团队在完成有项目归属的协作任务后，自动保留有依据、可复用的项目经验，并默认向符合条件的后续 AI 执行提供已采纳知识，减少普通成员填写知识表单和逐条确认的操作。

## Background

当前知识候选已有精确来源、人工决定、独立项目/工作空间贡献、撤回/到期和受控运行时注入，但没有系统提议/采纳身份、正式交付来源或自动整理工作。当前每目标最多 16 条贡献、128KiB。验收关闭原业务队列，后续整理不能恢复该队列。

事实依据：`research/default-enable-and-scope.md`、`research/extraction-resources.md`、`research/automatic-adoption.md`；补充契约见 `research/extraction-contract.md`、`research/reopen-and-compatibility.md`。研究基于当前有其他未提交改动的工作区，不代表产品测试或真实模型验收。

| R3 | 无项目任务不产生自动整理工作、候选或采纳，不自动转存工作空间；原有手动知识功能与合法知识消费不受影响。 | D3 |

| R7 | 显示系统或人工采纳方式、来源、触发验收、规则版本和证据情况；不伪造人类操作、测试证明或用量。 | D4,D6 |
| R8 | 整理异步执行，未配置模型、服务不可用和失败不回滚或阻塞业务验收；重试有界，不重复采纳。 | D5,D8 |
| R9 | 来源任务重开立即暂停由相关验收自动采纳的知识；重新验收后逐条复查，仍成立则恢复、内容变化则按规则形成新版本、冲突则待处理。保留人工采纳/撤回和其他任务知识；后台不能复活人工撤回版本。 | D6,D10 |
| R10 | 遵守任务的纯人工 AI 策略、来源边界和资源配置，不恢复关闭的业务队列、不重放原业务输入。知识使用、整理与采纳是不同控制维度。 | D6,D7 |
| R11 | 不静默淘汰旧知识或突破现有容量，满额保留明确的待处理结果。 | D9 |
| R12 | 统一复用服务端 AI 辅助模型配置，只发送必要且允许处理的资料，费用由该模型配置承担，记录实际模型与用量。管理员统一配置，普通成员不选择 Agent，不借用个人 CLI 账号，不依赖个人执行机在线。 | D8 |
| R13 | 项目自动采纳默认启用内置规则；当前有权的人类项目负责人或工作空间 owner/admin 可关闭、调整，并记录版本。系统默认规则不伪造某个人的启用，显式关闭不被默认升级覆盖。 | D9 |

## Scope

本次自动生产/采纳从现有协作任务的正式验收流程开始，覆盖他人交付验收与发起人正式自验收；共享 Web/Desktop 展示状态、项目策略与异常处理。已有普通任务的知识消费继续保留。

以下不在本次范围：

- 普通项目任务新增自动生产入口、把 ordinary done 当作协作验收、无项目自动沉淀。
- 自动提升为工作空间知识、跨项目传播、历史任务批量回填或已有候选批量自动确认。
- 把全部评论/日志直接保存为知识，强制每条任务产生知识，自动淘汰旧知识以腾出容量。
- 项目专用 CLI 整理 Agent、个人模型账号借用、多整理后端、新 Provider/远程消费支持。
- 模型训练、向量检索、任意规则脚本/DSL、自动打开来源 URL 或执行其中的命令。
- 自动切换纯人工策略、恢复暂停/关闭的原业务队列、覆写人工撤回或人工确认历史。
- 本轮产品实施、真实模型运行、生产部署及历史验收证据改判。

| AC2 | 有项目的正式验收触发后台整理；有准确来源且规则通过的候选无需逐条确认即可采纳，后续合格执行实际收到精确版本。 | R2,R4 |
| AC3 | 无项目任务产生零自动工作、零自动候选和零工作空间自动写入；原手动入口可用。 | R3 |

| AC5 | 来源缺失、过期、失权、引用错误、冲突或不确定不自动采纳；精确重复跳过；异常只向当前有权的人显示。 | R5,R6 |

| AC7 | 模型未配置/不可用、策略关闭、纯人工任务或后台失败不阻塞/回滚验收，不偷启原队列、不重放业务输入。 | R8,R10 |
| AC8a | 重开事务提交后，新的知识披露和启动授权立即排除相关自动贡献，不依赖异步扫描或 UI 刷新；原有合法历史可查看为暂停状态。 | R9 |
| AC8b | 重新验收后的复查可恢复仍成立内容、按规则生成变更版本；冲突、失权、过期、预算不符或检查失败继续暂停/待处理。旧事件和旧模型结果不能恢复它们。 | R9,R5,R11 |
| AC8c | 人工撤回/人工修订优先于后台迟到结果；人工采纳的版本及其他任务知识不被自动重开策略无条件暂停或重写。 | R9,R7 |
| AC9 | 16 条或128KiB容量已满时不删除/覆盖旧贡献，不假报成功，业务完成不受影响。 | R11 |
| AC10 | 统一服务端模型独立执行，未配置零外部请求；记录提供方实际返回的用量，缺失/超时标未知。个人 daemon 不参与提炼。 | R12 |
| AC11 | 无项目覆盖配置时使用默认策略；有权限者可关闭/调整，其他成员不能；默认升级不覆盖显式关闭，在途采纳服从新策略。 | R13 |
| AC12 | 新系统身份、交付来源、暂停/复查和协议形态有明确兼容行为；旧客户端不能把系统决定显示成人工确认，旧 daemon 不能通过降级续用被暂停的知识历史。 | R1,R7,R9 |

## Validation and limits

验证覆盖纯规则/协议、真实数据库事务与竞态、受控模型响应、共享 UI、Web/Desktop 流程和 daemon 实际输入。服务端模型提炼用 fake responses 验证结构、边界和编排；这不构成真实模型语义可靠性的证明。真实模型质量评测及更广平台矩阵保留独立证据和预算，不由本次规划冒充通过。

“立即暂停”指重开提交后新的知识披露/启动/续跑授权；不能收回已合法发送给正在运行模型的文本。UI 仍遵循既有实时提示与短期显示租约。
