# 跨工作空间协作分支合并 main 前修复与验收

## Goal

在保留并行会话工作与既有验收证据的前提下，处理 `codex/cross-workspace-collaboration` 合入 `main` 的已知检查阻塞，闭环核心回归记录，并给出绑定最终候选提交的可核查结论。

## Background

- 2026-11-23，用户先要求判断当前分支是否可以合并，再明确同意建立任务，并补充：“我还有几个提交在另外个一会话中，你别忘了重新检查或者等待一会再看看”。本次授权为创建任务并规划；未授权执行合并。
- 初次审查固定 `648d10fb8`，期间 HEAD 先后推进到 `76c61f95d`、`686e72293`、`cb192014b`。创建任务时已重新 fetch：`origin/main=dd87e0b33`，本地及远端功能分支均为 `cb192014b`，领先 main 858 个提交，main 仍是其祖先。此记录不表示另一会话已经完成。
- 已核实的检查阻塞、历史验收缺口和适用边界集中记录在 [研究基线](research/baseline.md)。原始数值仅适用于各自记录的 SHA；后续判断必须刷新。

| R2 | 验证绑定不可变的源码提交、相关源码/构建产物身份与运行配置。发现新提交后保留旧证据，检查新增差异并更新受影响的验证；不能把旧 SHA 的通过结果改名为新版本通过。若 main 推进且分叉，应验证实际集成结果。 |
| R3 | 图片体积检查能够处理当前约 3 MB 的差异列表，并正确保留 300 KiB 规则、缩小已有图片的允许语义以及现有显式豁免机制。修复 `scripts/check-image-budget.mjs:79` 的 `ENOBUFS`，不得通过跳过 CI、忽略归档目录或默认放行来消除失败。 |
| R4 | 提供最终候选的超限图片及归档材料清单、体积与用途判断。默认保留既有证据和 Git 历史；提出有证据支撑的处理方案与必要豁免说明，未经明确决定不得批量删除、重写历史或改写原始验收材料。未解决的图片门禁必须继续体现在最终结论中。 |
| R5 | 对 2026-11-21 核心报告中的五项未闭环用例逐项重新核对：两项本地化小队创建、S1 outsourcing、live revoke、terminal reopen。区分产品缺陷、夹具错误、环境前提与失效证据；当前候选上复验仍失败的，最小修复后重跑原始业务断言。日志缺失不能作为关闭依据。 |
| R6 | 对固定的最终候选运行适用的 lint/typecheck、TS/Go 测试、构建、静态与 CI 契约检查，以及生产 Web/对应 Desktop 核心回归。明确记录 pass/fail/skip/not-run 和平台限制；不能将旧版完整绿灯、静态收集或 fixture Provider 结果扩大为当前完整验收。 |
| R7 | 保留其他会话的未提交修改、暂存内容、任务状态、正常运行环境和数据库。只操作本任务明确拥有的文件、快照和测试资源；默认测试不得调用用户已登录的真实 Agent CLI。 |
| R8 | 交付合并准备报告，包含 source/base SHA、未提交及未推送差异、冲突/快进判断、检查结果、未关闭风险和下一步。既存评论管理员权限债务及已明确延期的真实 Provider 项单列，不伪称本分支新回归。 |

## Acceptance Criteria

- [x] AC1 / R1–R2：保留开始与结束的分支快照，并为期间每次候选变化记录新增提交、影响范围和验证处理；最终结论明确覆盖到哪个 SHA。
- [x] AC2 / R3：大差异回归在原脚本下失败，修复后通过；新增/增大超限图片仍失败，缩小和显式豁免仍遵守现有规则，实际候选检查完成而非 `ENOBUFS`。
- [x] AC3 / R4：最终图片/材料清单可审阅，检查结果与实际豁免状态一致；原有证据、历史和其他会话材料未被隐式删除或改写。
- [x] AC4 / R5：五项用例各有当前候选的结果与证据路径；修复保留原始失败、原因、回归覆盖和原业务断言的成功重放。任何仍失败或缺前提的项保持未关闭。
- [x] AC5 / R6：适用的完整本地检查及 CI 对应检查有新证据；未执行的远端/平台检查明确列为限制，不能声称 CI 绿灯。
- [x] AC6 / R7：其他会话的工作区修改保持原样，本任务环境具备来源及清理记录，无真实账号额度消费或正常环境破坏。
- [x] AC7 / R8：最终报告能明确回答“Git 是否能合并”和“质量是否达到建议合并条件”；有未关闭阻塞或未覆盖的新提交时，不给出无条件可合并结论。

## Out of Scope

- 在本任务创建/规划阶段实施产品修改、暂存或提交别人的工作。
- 自动合并到 main、推送、发布、安装器交付或部署；这些不是本次任务创建授权。
- 对 858 个历史提交进行不受边界约束的全面重构，或为缩减材料重写已有历史。
- 自动纳入独立任务 `11-20-comment-admin-human-authority` 的产品实现，或将已延期的真实模型、移动端和跨平台发布验收重新包装为本次已完成事项。

## Planning Decisions

- 用户于 2026-11-23 在最终规划后回复“开始”，已批准实施；当前 `in_progress`，限定修复和本地验收完成，本地工作提交已完成，剩余图片预算/远端 CI 合并条件明确保留。
- 候选会变化；可先做与最终 SHA 无关的规划/清单准备，昂贵验证使用固定快照。
- 既有材料默认保留；图片压缩或有理由的豁免属于可审阅的后续方案，是否满足门禁按实际执行结果判断。
- 本任务 owns 合并准备与限定修复；存在冲突的文件先协调或等待其所属会话完成，不通过覆盖工作区来取得“干净候选”。
