# F3 单一父任务预算根（观察首包）

父任务：`11-12-agent-squad-followup-roadmap`。本子任务只承接其中的 F3-S1（observe 首包），可独立验收和归档；roadmap 的 M1-S2–S6、F4、F5-A–E 不在这里。

## 目标

让当前有权的人能对一个普通父任务回答：它和已绑定子任务累计发生了哪些执行，哪些支出有可信回传、哪些只是估算、哪些未知，哪些预留还不能释放，以及某次原请求到底有没有记账。答案来自可重放的最小账目，不依赖模型总结、当前树形结构或小时聚合。

首包只观察，不拦截。

## 需求与可观察验收

逐行 expected 在父任务的 [F3 验收矩阵](../../../11-12-agent-squad-followup-roadmap/research/f3-acceptance-matrix-20261113.md)，本表是它的索引。

| ID | 需求 | 可观察验收 | 矩阵 |
| --- | --- | --- | --- |
| F3-01 | 一个普通父任务终身至多一个预算根 | 并行启用只成一个；关闭、删除后不能再建第二个；reopen 是同一根 | B01–B03 |
| F3-02 | 子孙任务在创建/绑定时继承并持久保存归属 | 启用与新建子任务并发时不漏绑；归属不依赖事后读取 parent | B04–B06 |
| F3-03 | 重试、重领、重开回到原根 | 新 task UUID、新 generation、业务重开都不重置累计或额度 | B07–B09 |
| F3-04 | 移动、改父、换项目、删除不退款、不换根、不双归属 | 已绑定成员之后的执行仍计入原根；跨根移动记录冲突；跨工作空间不可读写 | B10–B14 |
| F3-05 | 汇总不是第二笔消费 | 父层 rollup、旧 task_usage 行、hourly 桶都不增加已知实际 | B15–B16 |
| F3-06 | actual / estimated / reserved / unknown 分开 | 同一份额度不重复计入；未知不折成 0；没有证据不释放；有未知时剩余额度不给数值 | B17–B21 |
| F3-07 | 整数计量与冻结价格版本 | USD tick 整数、对外十进制字符串；旧事件按原价格版本重放逐位一致；调用方不能自报价格 | B22–B24a |
| F3-08 | 累计、增量、重复、迟到、更正各有确定结果 | 累计只追加差额；重复返回原收据；迟到旧值不倒扣；无依据的下降被隔离；显式更正可降低净值并保留原记录 | B25–B30 |
| F3-09 | 上报整批原子并可按原 key 恢复 | 部分失败不返回成功；响应丢失后原 key 得到原收据；结果未知时不另开根/调用/key | B31–B33 |
| F3-10 | 影子预留有完整生命周期 | 随领取同事务建立；取消/超时/失联转为未知占额而非释放；竞态只产生一份终结 | B34–B38 |
| F3-11 | 当前权限与旧版本拒绝 | 仅当前 owner/admin 且有根任务编辑权可管理；过期 revision 拒绝；撤权后新预留拒绝、已发生调用仍可收敛；Reporter 等不扩权；错误不泄漏 | B39–B44 |
| F3-12 | 首包不改变业务执行 | 超额、关闭、未知都只记录“若强制将拒绝”；未启用的任务树零影响；配置损坏是显式错误 | B45–B47 |

## 范围

- 纳入：单个普通父任务的根与成员；从启用点向前；人工 API/CLI 管理与查看；影子预留；幂等用量事件与更正；原请求恢复；quick-create 执行（D6）。
- 不纳入：按金额拦截或取消执行、调度排序变化、新 Web/Desktop 界面、项目/小队多根预算、跨根转移、无 issue 的 run_only autopilot、chat、独立 collaboration/host run、插件外部调用、多币种、账单对账。
- 不承诺：最终费用不超额；启用前历史成本；所有 adapter 都能给出实报金额。

## 约束

- 数据库：不加 FK/级联；每个索引单独一条 `CREATE [UNIQUE] INDEX CONCURRENTLY` 迁移。
- 现有 `ReportTaskUsage`、`task_usage`、hourly、`autopilot_quota` 的行为不变；它们不是预算账本。
- M1-S1 完成授权与 F2 报告快照不新增写路径、既有用例不变。
- 变更 CLI 命令或 API 字段时，同一提交更新相关内置 skill 的 `SKILL.md` 与 source map。
- 验收只用本地确定性夹具和任务自有数据库；normal 与 race 各用新建数据库并证明零 skip。
