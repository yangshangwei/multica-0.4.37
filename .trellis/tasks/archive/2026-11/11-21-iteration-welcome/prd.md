# 迭代首次使用欢迎页

## Goal

当迭代完整目录为空时，用简短介绍和可视化示例说明迭代如何帮助团队安排一段时间内的工作，并引导用户创建第一期。

## Background

- 迭代列表位于共享视图 `packages/views/iterations/iteration-overview.tsx`，Web 与 Desktop 共用。
- 当前列表对空数据只显示“暂无迭代”。
- 智能体、小队与自动化页面已有首次使用欢迎页；它们用简短价值说明、主要动作和本地示例界面展示功能。
- 单个计划中迭代的空任务状态已提供添加现有任务和新建任务操作，本任务不更改该状态。

## Requirements

- 仅当迭代功能已启用、迭代目录成功读取且完整目录为空时，显示首次使用欢迎页；该目录是当前客户端可获得的已保存迭代集合，不能声称知道已被删除的历史记录。
- 欢迎页说明迭代的核心流程：创建周期、安排并跟踪任务、结束时选择未完成任务的去向。
- 用明确标记为示例的迭代界面呈现周期、任务与进度；示例是静态展示，不读取、创建或修改真实数据，也不暗示未完成任务会自动结转。
- 提供一个主要的“创建迭代”操作，打开现有创建对话框；避免与列表头部重复显示创建入口。
- 保留迭代设置入口，且不新增独立欢迎路由或持久化“已看过”状态。
- 中文与英文文案齐全，窄屏布局可读且控件可操作。

## Acceptance Criteria

- [ ] 成功加载且完整迭代目录为空、功能已启用时，显示欢迎说明、静态示例和创建入口。
- [ ] 点击欢迎页主按钮打开现有创建迭代对话框；创建入口在首次使用视图中不重复。
- [ ] 创建或发现任何迭代后，欢迎页消失；即使当前“进行中”列表为空但目录含历史或计划项，也不再显示欢迎页。
- [ ] 功能禁用、目录仍在加载、首次读取失败或刷新失败时，不显示欢迎页。
- [ ] 有筛选条件时仍显示无匹配结果状态和清除筛选操作，而非欢迎页。
- [ ] 单个空计划迭代仍显示原有添加任务/新建任务引导。
- [ ] 英文与简体中文完整本地化；键盘与窄屏可访问。

## Out of Scope

- 更改迭代 API、数据模型、计划/进行中/历史筛选语义或创建表单。
- 改造单个迭代的任务空状态。
- 新增自动化的迭代周期、默认周期长度或自动结转行为。
- 增加首次引导完成标记、教学轮播或真实示例数据。

## Constraints

- 使用共享 `packages/views` 实现，保持 Web 与 Desktop 语义一致。
- 沿用现有产品色彩、语义令牌、控件与响应式容器模式。
- 空状态必须由真实成功读取结果推导；加载、错误或其他列表状态不能被当作空目录。
