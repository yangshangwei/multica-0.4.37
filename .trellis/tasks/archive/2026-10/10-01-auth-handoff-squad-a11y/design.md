# Boundary decisions

AuthInitializer is responsible for boot-time identity recovery and already settles a terminal failure through sessionExpired. The global API callback remains responsible for rejection after authentication has settled. Deferring that callback while the store is loading keeps route consumers from observing a false terminal state. ApiClient credential/endpoint epoch protections remain intact.

The squad avatar duplicates the adjacent heading text only in the template catalog composition. Hide it there, preserving the shared avatar's standalone semantics and appearance.
