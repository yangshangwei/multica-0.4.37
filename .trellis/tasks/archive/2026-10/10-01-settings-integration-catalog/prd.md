# 设置集成目录与详情页：初步方案

状态：设计预览已完成并通过浏览器验证，未进入生产代码实施。2026-10-01。

## 用户需求

- 点击设置中的“集成”先进入目录，而不是直接看到 GitHub 全部配置。
- 参考用户截图：分类标题、双列横向卡片、品牌图标、简短说明、状态和进入箭头。
- 点击 GitHub 后进入目前已有的 GitHub 功能。
- 用户已选择：以现有集成为主，少量未来集成作为示意。
- 最新调整：顺序为代码托管 → 任务管理 → 沟通与协作；沟通与协作展示“孚信 · 待规划”，移除应用与工具分区，后续优先推进任务管理。
- 本轮交付初步方案和预览，不修改应用业务代码。

## 推荐方案

采用“分类目录 → 单项详情”。保留设置导航，目录加宽至当前已有的宽内容档位；详情保持当前阅读宽度。桌面双列，窄屏单列。入口卡片整块可点击、可键盘访问，文字允许换行。

不采用页内折叠分组：仍会逐步变成长配置页，难以识别当前所在的集成。不采用新弹窗：GitHub 的连接、功能开关与仓库入口需要完整页面空间。

## 目录内容

| 分类 | 卡片 | 可用性与作用域 |
| --- | --- | --- |
| 代码托管 | GitHub；自托管 Git（GitLab / Gitea / Forgejo） | 工作空间；自托管 Git 保留现有部署开关 |
| 任务管理 | ONES、Plane、Kaneo | 后续优先推进；当前仍为方向示意，标“待规划”，不出现进入箭头、不接受点击，不承诺发布时间 |
| 沟通与协作 | 孚信 | 方向示意，标“待规划”，不出现进入箭头、不接受点击、不开放原型详情 |

目录当前规模不需要额外搜索、分类标签页或筛选器。未来数量明显增加时再考虑搜索。分类只有可见项时才显示。

预览展示代码托管、任务管理示意与孚信示意；正式页面必须依据实际部署配置过滤。GitHub 已连接、未连接及功能关闭状态均可预览，组织名称和状态全部为示例。

本次调整添加孚信待规划卡片、删除原型中的应用与工具分区及 Composio 详情与相关说明，并同步已有验证脚本和截图。应用内已有集成功能不在本次改动范围内。

## GitHub 详情

顶部增加“全部集成”返回入口、品牌标题与简短说明。主体复用 GitHubTab，保留：

1. 启用 GitHub 功能总开关。
2. GitHub App 连接信息、连接/断开操作及断开确认。
3. Pull Request 侧栏、Co-authored-by trailer、任务与 PR 自动关联。
4. 跳转“代码仓库”的快捷入口。

保留现有权限：普通成员可查看，连接与开关操作受当前权限限制。关闭功能不等于断开连接，目录和详情不能混淆两种状态。

## 实施边界与导航

- 共享目录和详情容器放在 packages/views/settings/components/；沿用当前各 provider Tab，不重写授权与业务表单，不新增依赖。
- 目录建议使用 `/{slug}/settings?tab=integrations`，详情建议使用 `/{slug}/settings?tab=integrations&integration=github`。
- 详情选择由 URL 驱动，使用共享 NavigationAdapter；浏览器返回、刷新、桌面导航均需一致。打开详情可 push，设置主标签切换仍沿用 replace 并清除残留 integration 参数。
- 后端 GitHub 安装回调仍使用 `?tab=github`，前端要将它解析为 GitHub 详情，不能只映射到目录导致授权后丢失上下文。聊天集成恢复设计时，再处理旧 `?tab=lark` 的详情定位；本轮不改应用内现有回调。
- 无效或被部署开关隐藏的 provider 不挂载详情，回到可用目录并给出简短提示。
- 目录加载失败时显示“状态暂不可用”并允许进入详情；不要把错误当成“未连接”。后续实现优先复用现有 React Query 数据，不引入新的全局状态或聚合接口。
- 查询、成员权限、GitHub master-off、服务端未配置提示与现有业务行为保持一致。
- 两种语言一起更新。MCP 和代码仓库的现有导航位置保持不变。

## 后续实施验收

- 集成入口默认显示目录，GitHub 表单仅在对应详情挂载。
- GitHub 卡片、返回目录、浏览器返回与刷新行为正确。
- 老链接和授权回调定位正确的 provider；主设置标签切换不带残留详情状态。
- 功能开关和部署配置正确隐藏入口与空分类；不可用详情不能绕过过滤。
- GitHub 现有权限、开关、连接、断开和仓库跳转回归通过。
- GitHub 总开关关闭时，子开关显示关闭且禁用；重新启用时恢复各子开关原有偏好，连接状态保持独立。
- 孚信与任务管理的待规划卡片不可点击，也不能通过详情参数打开；不出现应用与工具分区。
- 桌面、Web、窄屏可用；卡片可键盘激活，返回后合理恢复焦点；中英文长文本不溢出。
