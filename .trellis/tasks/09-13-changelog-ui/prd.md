# 桌面端变更说明页面与实时刷新

父需求：[`09-12-desktop-changelog`](../09-12-desktop-changelog/prd.md)。用户已要求完成设计、实现和验收。

## 验收标准

- [x] 帮助菜单增加“变更说明”，在工作区桌面标签页中打开；共享页面在 Web 可访问。
- [x] 按版本、日期和分类阅读更新，具备版本索引与适应窄窗口的布局。
- [x] 准确区分官方基线、本地待发布、正式发布和预发布，显示客户端与服务端版本上下文。
- [x] 页面打开时每 60 秒检查更新，并在重新进入、恢复焦点、重连和手动刷新时更新。
- [x] 断网、旧服务端、无内容、格式异常都有可理解的状态；刷新失败保留已加载内容。
- [x] 旧的桌面更新提示通过导航适配器打开应用内页面，避免公网依赖与 Provider 越界。
