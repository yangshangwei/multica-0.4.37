# M1-A1 报告员／评审员的最小 Multica API 权限

## 目标
新创建的进展报告员、代码／安全／迁移评审员使用任务令牌时，权限受真实任务范围限制，不能借运行时所有者身份修改任意资源或委派他人。复用现有身份、工作空间与生命周期机制。用户已授权子任务设计、独立审查、实现、测试、本地提交；原工作区有并行任务，本任务使用独立 worktree。

## 验收
- A1 新角色模板版本启用权限；旧版本、自定义角色、普通用户保持既有行为，显示名和用户输入不能授予权限。
- A2 报告员读取当前报告任务所属项目内任务、评论、活动；无项目仅当前任务。评审员仅读当前任务及评论／活动。不能伪造 UUID、标识符、workspace、查询参数扩大读取范围。
- A3 两者仅可向当前任务新增评论；拒绝通用更新、状态改变、批量更新、创建子任务、审批、运行时／身份管理、删除、附件写入和未知端点。
- A4 评论不得唤起任意智能体（显式 mention、回复、fallback、延后调度均不能绕过）。普通人／旧角色原有调度不变。
- A5 每次请求验证真实任务、claim generation、非终态、原发起人当前权限与运行时所有者当前工作空间授权；令牌过期、撤销、旧轮次、换任务／项目拒绝；DB 故障失败关闭。
- A6 领取冻结授权，同一领取事务内写入。两个领取入口一致；受限任务不获平台注入的外部 MCP／插件能力或额外 broker 凭据。已有权限机制依然是上限。
- A7 有失败及通过证据、独立实现后检查、限定测试库存、迁移／sqlc／Go 编译／静态检查证据。未验证项明确记录。

## 边界
这不是宿主文件系统／shell 沙箱；不对人类自带凭据或机器外部工具声称隔离。受限角色仅提交评论，业务状态由既有有权主体推进，不新增自动验收。跨工作空间协作独立状态机不改。M1其他能力、M2/M3尚未交付。无付费模型、生产、远程推送或发布。
