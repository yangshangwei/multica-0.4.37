# 需求文档：内网自助注册与登录

> 实施更新（2026-10-01）：用户已批准并启动开发。下文保留评审时的设计说明；当前完成项与未测边界以 [verification.md](verification.md) 为准。

## 目标

让公司内网用户以稳定、可识别的个人账号使用 Multica，换电脑后仍能访问同一账号的数据。首次使用保持简短，不依赖邮箱、邀请码或人工激活。

## 背景与已确认事实

- 当前桌面安装生成随机设备 ID，后端以此自动创建或复用用户；该机制不能可靠对应具体员工。
- 现有桌面支持服务器地址配置，现有欢迎引导包含关于你的信息、工作空间创建和运行环境连接，不重复建设。
- 用户选择用户名、密码、姓名三个注册字段；明确取消注册邀请码。
- 用户注册后自己为工作空间命名并创建，不需要系统管理员分配空间。
- 代码证据集中维护于 research/current-state.md。

## 角色

- 新用户：连接公司服务器，注册并创建自己的工作空间。
- 已注册用户：恢复会话或在其他设备上用用户名和密码登录。
- 旧设备用户：完善账号凭据，保留已有数据。
- 部署维护人员：配置认证模式，执行备份、迁移及必要的账号恢复。工作空间 owner 不因此获得系统级账号管理权限。

## 功能需求

| ID | 需求 |
|---|---|
| R01 | 复用服务器地址设置；连接成功后记住地址，允许修改，并明确显示当前服务器。 |
| R02 | 自助注册只必填用户名、密码、姓名；用户名在服务器内唯一，姓名允许重名。 |
| R03 | 注册成功即激活并自动登录；无邮件、邀请码、审批或额外激活步骤。 |
| R04 | 新账号进入现有欢迎引导，自己创建工作空间，继续现有运行环境配置。保留现有引导的可选项及校验。 |
| R05 | 已有账号通过用户名密码登录；恢复上次空间或现有空间选择行为，不重复注册或创建空间。 |
| R06 | 一个账号可在多个设备登录；业务数据、负责人和统计继续归属于同一用户 ID。 |
| R07 | 内网密码模式关闭随机设备自动开户和仅凭设备 ID 登录，不能只隐藏 UI。 |
| R08 | 可证明原会话归属的旧设备用户补填三个字段后沿用原用户 ID、空间、任务、评论；禁止按姓名自动合并账号。 |
| R09 | 网络失败、用户名冲突、认证失败均有可理解的反馈；失败不留下半注册账号或误进入欢迎流程。 |
| R10 | 密码不明文保存、不进入日志或分析事件；注册和登录有服务端输入验证及抗暴力尝试措施。 |
| R11 | 切换服务器不发送原服务器凭证，不显示原服务器缓存数据。 |
| R12 | 姓名用于展示，用户名用于识别和登录；即使姓名重复也不会混淆账号。 |

## 产品规则（工程初稿）

- 用户名建议 3–32 个 ASCII 字母、数字、下划线，首字符为字母；去首尾空格并转小写后判断唯一。第一版不提供用户名修改。
- 姓名建议去首尾空格后 1–80 个 Unicode 字符；保留现有资料编辑能力。
- 密码建议 12–128 个 Unicode 字符，UTF-8 最多 512 字节，不裁剪或改变大小写；不强制复杂字符组合。支持粘贴与显示密码，不加确认密码字段。
- 注册失败可重试；若服务端已成功但响应丢失，引导使用刚设置的密码登录，不能自动创建另一个账号。
- 注册并不开放其他人的工作空间；已有空间的成员规则不变。
- 姓名是用户自填的信息，不能将其描述为已核验的员工实名。

## 范围

包含桌面主路径、共享认证逻辑、服务端注册登录、现有 Web 登录入口的密码模式兼容、旧设备账号迁移和部署文档。Web 跟随服务端认证模式，避免同一部署出现另一条免认证入口；不重新设计 Web 全站。

不包含邀请码、邮箱验证、SSO、人工审核、公开用户目录或统计后台、移动端新登录 UI、自动合并多个旧设备账号、重做欢迎页面、自动加入别人的工作空间。

密码找回不接邮件。发布前提供受控的服务端运维恢复步骤；管理员重置 UI 和完整用户管理后台另立任务。

## 验收标准

| AC | 可观察结果 | 对应需求 |
|---|---|---|
| AC01 | 全新客户端连接服务器，仅填写三个注册字段即可获得账号；过程中不要求邀请码或收邮件。 | R01–R03 |
| AC02 | 注册后显示现有欢迎页，随后用户自行创建空间并进入运行环境步骤；注册接口本身不创建空间。 | R04 |
| AC03 | 重启应用恢复原账号；换一台客户端用同一用户名密码登录，用户 ID 与已有数据一致。 | R05–R06 |
| AC04 | 两人姓名相同仍可注册；规范化后相同用户名的并发注册仅一人成功。 | R02、R09、R12 |
| AC05 | 密码模式中直接调用设备登录、邮箱验证码或 OAuth 入口不能绕过当前认证策略。 | R07 |
| AC06 | 旧账号绑定后用户 ID、空间 membership、任务归属、评论作者保持不变；旧设备 ID 和绑定前的会话不能再换取访问。 | R08 |
| AC07 | 失败无半成品数据；断网、旧版本、服务端不兼容均可恢复或有明确升级提示。 | R09 |
| AC08 | 存储、响应、日志及分析中没有明文密码或密码哈希泄漏；限流在声明支持的部署形态下确实有效。 | R10 |
| AC09 | 从服务器 A 切到 B，B 收不到 A 的令牌/空间头，A 的旧响应不能覆盖 B 的状态。 | R11 |
