# 使用文档可视化说明

## 目标
让使用文档中的操作步骤、架构边界及执行原理可以通过实际渲染的图示理解，适合中文阅读和应用内查看。

## 需求
- R1：选择最有帮助的10页，约12幅图：核心概念、工作方式、开发架构、执行、协作、知识、AI小队、MCP、分拣、迭代。一图回答一个问题，保留步骤与权限文字作为解释。
- R2：中文 MDX 统一 Mermaid fenced code，服务器文档包保留图源，应用内与公共文档站均显示矢量图，不显示成裸代码。
- R3：沿用现有阅读风格与语义主题色，中文标签易读，深浅模式、窄窗口正常；应用内支持放大/缩放和源码查看，复用现有组件。
- R4：准确区分授权/执行、受理/完成、知识确认/实际使用、分拣接纳/触发执行。图示描述当前实现，不补虚构能力。
- R5：延迟加载 Mermaid，错误保留可读图源且不影响正文；保留严格渲染安全边界与已有普通代码块行为。

## 验收
- 所选页面图示与其正文和代码一致，源经生成器后完整保留。
- 应用内和文档站真实浏览器中所有新增图无语法/渲染错误。
- 桌面宽屏/窄屏、浅色/深色图示清晰；横向图不撑破页面；键盘可开启并退出放大视图。
- 相关单测、类型、lint、MDX构建和生成包/链接校验通过；独立语义及视觉复核通过。

## 范围
只扩展使用文档的图示与必要渲染接入，复用已安装 Mermaid，不新增依赖，不重做文档整体布局，不更改业务流程。不自动推送或发布。
