# 合并准备设计

## Boundary

本任务围绕一次合并建议组织检查，不改变产品范围或发布流程。主会话维护候选身份、证据清单、跨会话协调与最终报告；实施和独立检查按 Trellis 的 `trellis-implement` / `trellis-check` 分配明确写入范围。

产品文件仅在当前候选真实复现 R5 问题后，作为修复的最小必要范围进入任务。检查脚本的初始范围为 `scripts/check-image-budget.mjs`、其有意义的回归测试和必要 CI 测试接线。

## Candidate identity and concurrent commits

每次检查以三元组标识：`source_sha`、`base_sha`、`validation_sha`。若 main 是 source 的祖先，候选树可以直接验证；若已分叉，在任务私有 checkout 中生成实际集成候选并记录其身份。根工作区保留给既有会话，不 checkout、stash、reset 或清理其改动。

观察点为：任务建立后、正式验证前、修复集成后、最终报告前。每次记录 fetch 结果、HEAD、远端分支、origin/main、暂存/未提交路径以及与上一候选的差异。用户已经说明另一个会话仍有提交，因此时间上的短暂稳定只说明当前观察结果，不能断言提交已收齐。

新提交到达时：

1. 保留旧快照与测试结果的原始绑定。
2. 比较完整新增差异，不能只看提交标题。纯文档变化与产品/构建/测试依赖变化分别评估。
3. 更新候选、重建受影响产物并补跑必要检查；无关检查只能在源码与输入相同且可核查时引用原证据。
4. 结束时若还有未覆盖提交，报告旧候选的有限结论和新差异，不能宣称分支已准备好。

## Image check repair

现脚本一次同步缓冲全部 `git diff --name-status` 输出，超过 Node 默认 1 MiB。当前约 3 MB 的列表已经复现崩溃。

优先用不依赖总列表大小的读取方式处理 Git 输出；可以先在 Git 层过滤位图路径以减少无关数据，但仅调整固定 `maxBuffer` 或仅过滤文件不能作为无界规模的完整方案。使用明确的 argv 和 NUL 分隔路径，避免空格或换行路径破坏解析；保持 Git 错误非零退出。最终实现选择以最小可读改动和回归证据为准，不引入依赖。

测试通过临时 Git 仓库或受控 Git 子进程数据证明：大列表完整处理、超限新图/增大图拒绝、缩小允许、已有显式豁免允许以及 Git 失败可见。修复应保持当前 300 KiB 阈值和 PR 正文豁免格式，不扩大豁免范围。

## Evidence and image disposition

使用 Git blob 大小形成已提交候选清单，未跟踪材料单独统计。禁止从用户工作区体积推导 commit 的体积。保存精简摘要、源 SHA、路径、大小和哈希；原始截图、trace 和日志默认保持原样，不向 Git 再提交大批重复输出。

既有图片预算规则包含显式 PR 说明豁免。后续处理方案可以提出适合展示用途的压缩交付或具体、有理由的豁免草案，但不能伪造 PR 已存在、豁免已获接受或 CI 已通过。历史重写、批量删除和扩大免检目录均不属于默认方案。

## Regression closure

五项历史失败先核对提交后的变化和原始夹具。报告和部分日志缺失只能说明证据不完整。用任务私有数据库与配置，运行原始用例，保留最初失败和重放结果：

- 本地化小队两项：模板加载、进入创建页与语言化角色/重名处理。
- S1：知识披露的唯一可交互目标与完整业务语义，修复定位器时不弱化断言。
- live revoke / terminal reopen：按实际密码/managed 配置启动，正确开启测试环境 gate，保留重新注册离线 runtime 后的权限/状态检查。

环境错误修夹具，产品错误修 owning layer。任何复现都禁止借用用户的真实运行时或账号。

## Verification and rollback

沿用 `.trellis/spec/web/frontend/e2e-run-environment.md`：生产 Web、明确的 Desktop renderer/native 类型、任务私有 API/数据库、单 worker、零自动重试，记录构建与进程身份。默认 Go 测试走现有 Agent CLI guard。`make check` 覆盖主要本地流水线；额外核对 CI 的图片预算、生成产物一致性、静态分析及平台检查。

检查结果分别记录成功、失败、跳过、未执行和前提不足。只清理本任务持有的资源；回滚只涉及本任务差异或私有 checkout，不撤销其他会话提交。main 分支不在本阶段被修改。
