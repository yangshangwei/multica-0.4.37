# Git 物料运行时执行改造与真实验收

状态：in_progress；2026-11-27 用户确认采用当前需求、设计和接口合同，进入实现与验证。2026-11-27用户明确要求修改需求、设计和代码：GitHub/GitLab操作仅依赖所选底层运行时，不依赖App。本次代码改造及确定性验证是当前交付；真实仓库/模型验收继续保留，独立落实运行环境与执行条件，不阻塞代码设计。

## 目标

用户在项目中选定运行时（例如Codex）后，物料发布、PR/MR操作、人工批准后的合并以及方案生成均由该运行时完成。Git身份留在运行环境，Multica无需GitHub App或GitLab服务端连接。Multica继续负责物料版本、人工审核、调度和结果记录，只有实际远端内容核验通过才能形成正式基线。

## 当前代码交付要求

- R0：配置和运行不要求App、安装记录、服务端Git凭据或VCS连接。GitHub与GitLab遵守同一运行时产品语义。选定运行环境承担Git写入；Multica服务器不直接调用Git写入或带凭据读取API。
- R1：执行身份必须来自用户显式选择的运行时。每次尝试固定runtime/daemon/profile配置和授权人；离线、删除、权限撤销、配置变化时不自动转移其他机器/Agent。保存配置不代表Git认证就绪。
- R2：复用普通任务队列、原生运行时执行与现有进度/终态机制。一个逻辑操作最多一个活动尝试；调度租约超时不代表外部操作未发生，不自动重复启动模型或重复写Git。
- R3：可评审候选才自动发布，人工审核只接受真实有权人类并绑定当前修订/HEAD。发布阶段不能由Multica授权为合并阶段；过期、撤回或无权审批均不推进。批准仍不能授权编码。
- R4：写入由所选运行时执行，运行端在同一任务上下文进行独立只读远端核验并回报实际PR/MR、目标、HEAD、完整变更、原生门禁、提交及文件字节。模型JSON、普通完成文本或单一PR链接均不能建立正式基线。
- R5：保留普通草稿、审核历史、待办/自动启动、完整基线交接与人工重试语义。计划启动前的Git读取也迁到运行端，不保留隐藏服务端App依赖。
- R6：Web/Desktop共用一个运行时选择入口，显示真实queued/running/blocked/unknown结果；运行时在线不等于Git已认证。加载失败保留输入，权限丢失清除私有读数据，旧待重试配置不可静默改写后沿用旧request_id发送。
- R7：旧App配置没有runtime时显示需重新选择；旧修订和决定保留原样，在途操作不静默迁移。已有合并基线保持身份，可在新授权运行时核验后继续。运行时删除不删除物料和任务审计历史。
- R8：默认验证不用真实账户/模型。以测试构建的runtime可执行程序驱动实际队列→执行→远端fixture→运行端只读回执→服务端状态链，证明未配置App/VCS也可工作；不能靠直接写最终回执或状态取得通过。

## 当前验收条件

- [x] C1：两provider在无App/VCS配置和连接记录时可配置runtime并派发；服务端无Git凭据解析和远端操作路径。
- [x] C2：只有显式选择的运行时执行发布/合并/规划；配置或权限变化拒绝旧尝试，runtime删除保留历史，普通任务不回归。
- [x] C3：未批准/旧HEAD/撤回不能获合并阶段；机器身份不能自批。范围外文件、不完整列表、错误模式/摘要、未实际合并均不能成为基线。
- [x] C4：假造模型回执、无当前daemon领取绑定的调用者及task-token伪装daemon、错误任务/runtime/generation/nonce、重复键不同正文均拒绝；同一真实回执丢回复后可恢复。
- [x] C5：发布/合并响应丢失及进程中断先核对事实，租约到期无重复活动模型；原生门禁待满足不每轮开启新模型。
- [x] C6：关闭自动方案时零模型启动，人工启动/终态重试复用issue；完整基线内容经运行端核验后才能启动方案，方案审核不启动编码。
- [x] C7：共享UI无Git连接/方案Agent前置项；runtime必选、明确故障、原请求恢复和私有数据保护通过测试（15项core、34项shared UI/picker；生产旅程归C8）。
- [x] C8：迁移/query生成、相关Go回归/竞态、TS测试、lint/typecheck/build及Web/Desktop确定性旅程通过，更新技能与规范并记录限制。

## 不在范围与保证边界

不新增托管平台、通用工作流引擎、跨模块编码/QA/发布编排或安装包交付；不改无关GitHub/VCS功能。真实模型和远端测试的对象/次数/停止条件在后续执行清单中明确。

运行时主机是受信任执行环境。Multica可控制自己的阶段授权与基线接受，不能仅靠提示词约束持有宽权限Git凭据的任意shell；外部越过流程的合并不得被Multica接受为获批基线。此次不宣称新增操作系统/网络级沙箱。
