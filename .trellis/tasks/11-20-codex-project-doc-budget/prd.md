# Codex 注入指令：完整读取预算

状态：规划交付；产品实现未启动。2026-11-20 用户授权建立独立产品任务。来源：[安全漏洞修复小队 v2](../11-18-security-remediation-squad-v2/prd.md)，子任务一 design.md 14.2 平台项 B。

## Goal

守护进程在每次 Codex 启动/恢复前对实际注入的完整说明计算读取预算，避免默认 project_doc_max_bytes 把安全边界、花名册、工具或输出要求静默截断。

## Requirements

- 长度以实际写盘后的 UTF-8 字节数计算，包含平台说明、角色指令、自治策略、协议、花名册、小队正文、工具与流程结尾；不能用字符数或模板单文件长度代替。
- 明确所有会消耗 Codex 项目文档预算的祖先/覆盖文档与来源顺序；无法准确确定时应拒绝或明确诊断，不能称已保证完整。
- 配置优先级：显式用户有效值优先于自动默认。用户值足够时原样保留；显式值不足时拒绝启动并报告 required/configured 字节数及修复方法，不能静默调大用户有意限制。未配置时按完整预算生成任务私有配置。
- 缺省、零、负数、非整数、溢出、重复键、配置表位置和 CLI/profile 覆盖都必须有明确规则；非法或无法确定的有效配置不得静默启动。
- 只修改任务私有 Codex 配置；不改用户共享 config.toml。托管键与用户键无重复 TOML，重复准备、恢复、指令增大/缩小均重新核验。
- 自动预算需定义产品上限及超限处理，不能用无限大常量掩盖无界输入；错误不得包含指令正文、凭据或路径中的敏感部分。
- 启动前证明有效配置覆盖最终文档；运行时验证必须结合实际 Codex 版本与原生输入/可观测尾部哨兵，区分配置正确、确实读取和模型遵守。
- 对已有 v1/v2 小队及其他长指令通用；不自动升级工作空间模板副本，不改模型选择与账号。

## Acceptance Criteria

- [ ] 多字节中文、边界相等/少一字节、长尾、组合说明、祖先文档、重复准备/恢复矩阵通过。
- [ ] 未配置可生成足够预算，显式足够值保留，不足/非法值拒绝且不启动 Provider。
- [ ] 共享配置原样保留；任务配置无重复键、托管块位置正确、profile/CLI 真实优先级有验证。
- [ ] 超过产品上限、配置写入失败、指令文件变化或无法计算输入时不发生模型调用。
- [ ] 默认测试仅用 fake/missing CLI；adapter/execenv 整包、race、vet、gofmt 通过。
- [ ] 如申请真实 Codex 验收，单独限定型号、账号、调用次数与时间，Go 入口受 agentintegration + MULTICA_RUN_REAL_AGENT_SMOKE=1 双门保护；保存脱敏摘要和会话哈希，观察输入尾部。

## 范围

实现位置以 execenv 最终注入与 Codex 启动前配置边界为准（codex_home.go、codex_sandbox.go、runtime_config_sections.go、pkg/agent/codex.go 的相关调用）。不借本次安全小队验收授权为此独立任务消费账号额度。临时手工配置保留至此任务完成并验证。
