# 迭代设置：工作空间内启用与管理

状态：实施收尾中；用户已于 2026-10-09 授权按父任务 [closeout-plan.md](../10-08-iteration-workspace-settings/closeout-plan.md) 完成修复、验证、提交和归档。此前的规划状态由该授权取代。

## 目标与背景

工作空间所有者或管理员在“设置 → 工作空间 → 迭代”中直接管理迭代，无需修改服务器配置或重启服务。用户提供分拣台设置截图作为布局和组件的明确参考，桌面端是主要验收平台，Web 使用相同业务界面。

当前迭代设置藏在列表页的折叠区域，导航和写操作又受部署总开关控制。已经存在的工作空间设置、手动生命周期和关闭事务可以复用。

## 页面与行为要求

| 编号 | 要求 |
| --- | --- |
| ITS-01 | 设置导航在“工作空间”分组的“分拣台”之后增加“迭代”，无论当前工作空间是否启用都能找到。只影响当前工作空间，Web/桌面端共享状态。 |
| ITS-02 | 使用与分拣台相同的标题、说明、分组卡片、左右字段行和开关。标题为“迭代设置”；首屏突出启用开关，第二部分是规划时区。 |
| ITS-03 | 服务支持能力与工作空间启用状态分离。退出 `iterations_i1` 部署开关，普通管理员不需接触配置文件；新工作空间默认未启用，既有状态保持。 |
| ITS-04 | 只有当前工作空间的所有者或管理员可修改设置，服务端保留人类身份与事务内权限检查。普通成员可查看设置和有权限的历史，控件只读且说明原因。 |
| ITS-05 | 开启开关使用页面明确展示的已保存规划时区，等待服务端成功后显示已启用；开启不创建迭代、不安排任务、不启动执行。无额外总“保存设置”按钮。 |
| ITS-06 | 关闭开关先打开影响预览，开关仍显示已启用；展示全部受影响的进行中/计划迭代、任务数量和可展开明细，填写关闭原因，再明确确认。取消、失败、超限均不关闭。 |
| ITS-07 | 确认关闭后，进行中迭代结束并冻结历史，计划迭代取消，任务当前迭代归属清除；任务状态、项目、负责人、累计结转次数和正在运行的执行保持原样。全部副作用原子提交。再次启用不复活旧周期。 |
| ITS-08 | 规划时区使用现有时区选择器；明确与项目规划共用，既有迭代保留自身时区。时区独立“保存时区 / 取消修改”；有未保存修改或正在保存时，禁用启停开关并解释。 |
| ITS-09 | 周期管理方式显示为只读“手动”，说明成员手动开始/结束且同时最多一个进行中迭代。保留现有业务规则，不提供尚未实现的自动推进、自动加入、容量或估算选项。 |
| ITS-10 | 启用时工作侧边栏显示“迭代”；未启用时从设置进入。关闭后保留“查看历史”入口及已有直达链接。旧列表页将配置折叠区替换为设置链接，保留迭代创建、列表、详情和历史功能。 |
| ITS-11 | 启停未知结果可在当前设置页及重新进入后恢复，沿用原请求身份；处理时锁定重复操作，不根据开关值推断某次请求是否成功。权限被撤销时清除不可访问数据。 |
| ITS-12 | 支持加载、空状态、只读、旧后端不支持、请求失败、并发冲突和保存反馈。后台刷新失败保留草稿；失败不得显示为成功。启停及共享时区变化应刷新相关视图，其他已打开客户端无需重启看到状态更新。 |

## 业务说明与范围界限

- 当前周期名称、日期、协调人、任务安排和结束结转仍在迭代业务页操作。
- 时区是工作空间共享规划设置，不是此设备偏好。
- 统计继续按任务数计算；本次不添加默认周期长度、默认协调人、通知策略、点数估算或自动排期配置。
- 本次不制作移动端设置页，不改变既有历史统计或执行规则，不新增依赖或数据库表。
- 不自动为任何工作空间启用功能，不修改真实环境的配置、数据或当前运行状态。

## 可观察的验收标准

| 编号 | 验收结果 | 覆盖要求 |
| --- | --- | --- |
| AC-01 | 桌面端和 Web 均能从设置找到“迭代”，并能用 `?tab=iterations` 直达；未启用时仍可发现设置。 | ITS-01,02,10 |
| AC-02 | 无 `FF_ITERATIONS_I1` 或旧值为 false 时，新工作空间仍未启用；管理员可在页面启用，已有启用状态不会被迁移覆盖。 | ITS-03,05 |
| AC-03 | 普通成员、机器凭据、失去管理员权限的旧页面无法绕过服务端改变启停/时区；跨工作空间不可读写。 | ITS-04,11 |
| AC-04 | 开启后列表入口出现，可创建迭代；本身不生成周期或任务、不启动执行；其他客户端收到状态更新。 | ITS-05,10,12 |
| AC-05 | 切到关闭时先展示完整影响及原因；取消仍启用；确认后一次性结束/取消/清理，任务与执行保持不变。 | ITS-06,07 |
| AC-06 | 关闭影响超过当前后端 2,000 条任务上限时无任何变更，提示先整理迭代；并发变化须重新预览。 | ITS-06,12 |
| AC-07 | 禁用后可以从设置查看保留历史，旧链接仍工作；重新启用不恢复旧周期或任务归属。 | ITS-07,10 |
| AC-08 | 时区单独保存或取消；草稿/保存中阻止启停；新周期使用保存值，旧周期的日期与快照不变。 | ITS-08 |
| AC-09 | 启停请求提交后响应丢失，可凭相同请求恢复结果，不重复关闭、重复通知或覆盖后续启停。 | ITS-11 |
| AC-10 | 旧后端缺失能力接口时显示不支持，提供重试；真实撤权不伪装为旧版本。 | ITS-03,12 |
| AC-11 | 中文/英文、键盘开关和对话框操作、深色及窄窗口无溢出；所有关键状态有可读反馈。 | ITS-02,12 |
| AC-12 | 设置只展示已经支持的业务；分拣台的迭代分配能力、任务选择器和共享项目时区跟随变化更新。 | ITS-09,12 |
