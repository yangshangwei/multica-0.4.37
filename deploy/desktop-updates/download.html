从安装到工作台

首次使用，按以下步骤完成。已有账号可以直接登录。

  1. 下载安装包

    在本页点击 下载（.exe），等待下载完成。首期安装包适用于 Windows 64 位（x64）；可在 Windows「设置 → 系统 → 系统信息」中查看系统类型。

  2. 安装并打开 Multica

    打开下载的安装包，按安装向导完成安装，再从桌面快捷方式或开始菜单打开 Multica。若安装被系统或组织策略阻止，请联系内网管理员确认安装包来源与安装权限。

  3. 测试并保存服务器地址

    复制上方的业务服务器地址，填写到客户端首次启动的服务器设置中。先进行连接测试，成功后保存并继续；连接失败时核对协议、主机、端口及内网连接。

  4. 注册新账号，或使用已有账号登录

    首次使用：进入注册入口，填写用户名、姓名、密码和确认密码，按表单提示提交。注册成功后会自动登录，无需再登录一次。

    已有账号：输入用户名和密码登录。如果没有注册入口，请联系内网管理员确认是否已开放自助注册。

  5. 加入或创建工作空间

    已收到邀请：按客户端提示接受工作空间邀请，加入团队。若邀请未出现或失效，请联系邀请人或内网管理员核实账号与邀请。

    没有邀请：按上手引导创建工作空间；如果团队已有工作空间，也可以先联系团队成员获取邀请。

  6. 完成引导，进入工作台

    完成客户端剩余的上手引导，进入已加入或新建的工作空间。遇到运行时或 AI 工具连接步骤时，可使用客户端的稍后处理入口。看到工作空间内的工作台后，即完成首次安装与接入。

常见问题

下载按钮不可用，或安装包下载失败？

先确认已连接内网，再点击页面上的「重新获取下载信息」或刷新页面重试。若仍无法下载，请联系内网管理员检查当前安装包是否已发布完整。下载中断时，重新下载完成后再打开安装包。

Windows 阻止安装，或提示权限不足？

保留提示内容，联系内网管理员确认安装包来源、系统架构和安装权限，并按组织的软件安装流程处理。不要使用来源不明的替代安装包。

客户端无法连接服务器？

核对填写的是本页提供的业务服务器地址，包含完整协议和端口，不要填写浏览器中的下载页面地址。确认内网连接后重新测试；若地址未显示、证书异常或连接持续失败，请联系内网管理员。

为什么没有注册入口？

注册入口取决于业务环境是否启用了密码登录和自助注册。本页面不能修改该设置，请联系内网管理员确认开放情况；已有账号可以直接登录。

用户名或密码有误，无法注册或登录？

按客户端表单提示检查用户名、姓名及密码要求；注册时两次密码须一致。登录时检查用户名、大小写和输入法。如提示需要等待，请在提示时间后重试；忘记密码或仍无法登录时，请联系内网管理员处理。

登录后没有工作空间，或仍停留在引导中？

有邀请时接受邀请加入团队；没有邀请时按引导创建工作空间，或联系团队成员发送邀请。继续完成客户端要求的上手步骤，运行时连接可稍后处理。若邀请无效或无法创建，请联系内网管理员。
