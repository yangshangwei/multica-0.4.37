[协作空间](/collaboration)提供两种保存结论的方式。**协作上下文**记录这条任务当前做到哪里；**知识候选**把有来源依据的结论提交给项目或工作空间，在确认后用于符合条件的后续工作。

## 维护协作上下文

打开协作任务，在**任务资料**区域选择**协作上下文**，右侧面板会显示当前文档、版本、写入者、保存时间及大小。

每条协作任务有一份 Markdown 文档。不同机器和账号上的智能体可以接续维护，有 AI 控制权的有效参与者也可以点击**编辑协作上下文**纠正内容。仅能查看来源工作空间任务、但未加入协作参与者的人不能编辑。任务结束后，编辑和恢复入口只读。

建议保留：

- 当前目标、已确认的约束与验收条件；
- 已验证的发现，以及仍待确认的问题；
- 已作出的决定和依据；
- 下一步、负责人及需要继续查看的文件或记录。

把文档整理为“当前状态”，详细的尝试过程仍写在评论里。保存时会创建新版本。默认大小上限为 **128 KiB**，实际以面板显示为准；UTF-8 字节数不等于字数，超限时需要精简后再保存。

如果编辑期间别人或智能体已经更新了文档，系统会保留你的内容并提示冲突。先查看当前版本，合并修改后再保存，避免覆盖别人的进展。

## 版本历史与恢复

在**版本历史**中打开某一版本，可以检查当时的正文、写入者和来源执行。选择**恢复为新版本**会把旧正文保存为一个新的当前版本，之后的历史不会被删除。

任务发起人可以填写原因并**清除历史版本的正文**，例如处置误写入的凭据。正文清除后无法恢复，版本号、大小、写入者和清除记录仍保留。当前版本不能直接清除，应先编辑当前文档；已清除的历史正文不能用于恢复。任务完成或取消后，发起人仍可处置历史正文。

## 提出知识候选

可复用结论可以由任务发起人或当前处理人在**任务资料 → 知识候选**中提出。仍需保有来源任务的访问权限，并能选择有效的目标范围。

1. 点击**提出知识候选**，填写摘要和 Markdown 结论。
2. 选择目标项目或工作空间。按当前权限，可以选择来源范围或其他可见目标；提出候选不会获得目标的管理权限。
3. 从**协作上下文、评论、运行记录**选择准确的来源版本。后续编辑不会替换已经选定的来源。
4. 填写适用场景，按需要设置到期时间和验证说明。
5. 点击**提交候选**，等待有权限的人审阅。

验证说明是提议者对测试、提交或运行观察的声明。即使标记为“提议者已验证”，也需要审阅具体来源和依据。

## 审阅与确认

目标工作空间的所有者或管理员可以确认/拒绝候选；目标是项目时，该项目的**人类负责人**也可以。审阅者还必须能够读取来源任务。确认时，来源材料须可读取且候选未到期。

打开**审阅候选**，检查结论、目标范围、来源版本和验证说明，确认已经审阅后选择**确认此版本**，或填写决定说明并拒绝。

确认表示允许这份结论在满足条件时使用，不代表系统已经验证提议者的声明，也不代表它已经进入某次智能体执行。

## 管理知识贡献

确认后的内容称为**知识贡献**，可在目标项目详情，或工作空间**设置 → 通用**的知识贡献区域中查看。它与手动编辑的项目说明、工作空间上下文分别管理。

| 操作或状态 | 含义 |
| --- | --- |
| **提出修订版** | 提交新版本供审阅；新版本确认前，现有已确认内容保持不变。 |
| **提出工作空间版本** | 把适合更广范围的项目结论作为新候选提出，仍需相应确认。 |
| **撤回贡献** | 停止后续使用；任务发起人/当前处理人或有目标确认权限的人按当前权限操作。 |
| **已替代** | 已有确认的新版本取代该版本。 |
| **已到期或来源不可用** | 不再满足后续使用条件；来源无权读取时，相关正文与引用会隐藏。 |

知识不会因为一次确认就永久绕过权限。每次使用都会重新检查来源访问、目标范围、适用场景和有效期。

## 智能体何时会使用知识

知识候选的提出与确认，不要求智能体正在运行。运行时使用还取决于部署与执行条件：

- 管理员需要明确启用 `MULTICA_KNOWLEDGE_CONTEXT_ENABLED=true`，默认关闭。
- 当前运行时、AI 编程工具和执行模式需要支持知识能力，且本次执行满足权限和有效期检查。
- 协作执行还需要匹配的运行时协议；当前普通本机执行的知识支持覆盖符合条件的内置 Claude Code、Codex 本地运行时，自定义运行时配置不在该路径内。

因此，看到“已确认”不能推断所有智能体都会自动收到该内容。部署配置见[环境变量](/environment-variables)，具体运行情况应结合该次执行记录检查。

## 保存或确认超时

出现“结果待确认的知识请求”时，先使用**查询原请求结果**；需要重试时使用**重试原请求**，保留相同输入和请求身份。

**移除本地记录**只清理当前设备上的恢复记录，不会取消服务器请求，也不会撤销已经处理的结果。无法读取来源、目标已变更或权限不足时，按提示刷新并重新审阅当前内容。
