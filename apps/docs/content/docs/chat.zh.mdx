对话适合还没有形成明确任务的工作：梳理想法、查询工作空间情况、讨论方案，或者先让智能体完成一个小任务。

**聊天（Chat）是你和一个[智能体](/agents)的独立对话**，适合讨论方案和处理私人草稿。对话不会自动关联任务，也不会因为开始聊天就创建任务。其他工作空间成员和管理员不能读取你在应用内创建的直接对话。

对话**不绑定某一条任务**：智能体不会自动收到任务的描述和评论，但仍可以在权限范围内用 Multica CLI 查询工作空间、项目、任务和 skill。

对话也可以携带背景。点击输入框左下角的 **+**，选择**项目上下文**，为对话挂上一个[项目](/projects)；智能体执行时会收到该项目的描述和仓库等资源。

## 开始对话

1. 打开侧边栏中的**聊天**。
2. 点击新建，选择一个你有权运行的智能体。
3. 输入消息，也可以附加图片或文件。
4. 发送后，Multica 会为这条消息创建一次执行，回复会回到当前对话。

选择器支持按名称、职责和分类查找，也能从最近使用或常用智能体中选择。小队队长会显示其带领的小队，但选中的是**队长这一个智能体**，不会自动让整个 AI小队参与聊天。需要由小队协调交付时，创建任务并[分配给 AI小队](/squads)。

智能体需要绑定运行时才能发送消息。运行时仅暂时离线时，消息会排队等待；未绑定运行时、运行工具不可用、智能体已归档或调用权限已撤销时，不能继续发送。只允许关联任务执行的[受限角色模板](/agents-create#角色模板)不适用于直接聊天。

第一条消息发送前，对话页会显示所选智能体配置的最多三个建议。选择后会把完整提示词填入输入框而不会发送，方便你先调整。未配置建议的智能体会使用本地化的通用示例。

添加项目背景时，如果界面提示守护进程版本过旧，应先升级对应运行时；旧版本可能无法把项目描述提供给智能体。

## 对话与 issue 的选择

| 需要 | 更适合 |
|---|---|
| 快速提问、探索方案或处理私人草稿 | **对话** |
| 明确负责人、状态、优先级和交付结果 | **任务** |
| 让团队成员查看背景并继续讨论 | **任务** |
| 临时查看工作空间信息，不需要建立工作记录 | **对话** |

在 Multica 中创建的直接对话只对创建者开放，其他工作空间成员和管理员不能读取。需要团队共同查看的结论，应整理到任务、项目说明或 skill 中。

## 多轮上下文

同一段对话会尽量继续 AI 编程工具中的原会话，因此后续消息不需要重复前面的内容。Multica 会保存会话标识，并把后续执行路由到能够访问该会话的运行时。

如果本地会话已经不存在、上下文无法继续，或者上一次错误不适合复用，运行时会从新会话开始。对话中的历史消息仍然保留。

## 查看和停止执行

智能体运行时，界面会显示当前阶段和工具活动。展开**查看详情**可以检查更完整的执行过程。

需要中断时，点击输入框旁的停止按钮。已经返回到对话中的内容会保留；尚未开始处理的输入会尽量恢复到编辑框中。

## 整理对话列表

对话支持重命名、置顶、归档和删除：

- **置顶**把常用对话固定在列表前面；
- **归档**把对话移到"已归档"并设为只读；
- **取消归档**后可以继续发送消息；
- **删除**会永久移除对话及其中的消息。

如果对话绑定了外部渠道（如 Slack），归档时绑定会断开，取消归档不会恢复，需要重新绑定。

<Callout type="warning">
删除对话无法撤销，并会停止其中尚未结束的执行。暂时不需要时用归档。
</Callout>
