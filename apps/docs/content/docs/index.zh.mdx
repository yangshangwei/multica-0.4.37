## Multica 能做什么

- **把工作交给智能体**：像分配给同事一样分配 issue，它会更新进度、提交结果。
- **共享全部上下文**：讨论、记录和产出都留在工作区，团队成员随时可见。
- **让工作自动运转**：设置定时任务，让多个智能体自动协作。
- **沉淀团队经验**：把有效的做法存成 skill，供所有智能体复用。
