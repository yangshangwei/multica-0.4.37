从侧边栏打开**统计**，可以查看当前工作空间的**用量**和**错误**。先确认时间范围与项目，再比较数字；这里的 task 数表示智能体执行次数，不是业务任务数量。一条任务多次执行会产生多条记录。

## 选择范围

1. 打开**统计**，选择**用量**或**错误**。
2. 选择时间范围：`1d`、`7d`、`30d`、`90d` 或 `180d`，默认 `30d`。
3. 选择**全部项目**，或限定到一个项目。
4. 查看页头的时区与更新时间；需要获取最新结果时点击**刷新**。

`1d` 指查看时区中从零点开始的今天，并非滚动的最近 24 小时。跨日期比较时，要使用一致的时区和范围。

图表的**按天 / 按周**只改变当前图表的汇总方式：`1d`、`7d` 只按天，`30d`、`90d` 可以切换，`180d` 只按周。周图可能包含未满一周的区间，图中会注明已覆盖的天数，不宜直接与完整周比较。

## 查看用量

| 指标 | 如何理解 |
| --- | --- |
| **费用** | 提供商已上报的金额，加上尚未上报金额部分的 Token 费用估算。 |
| **Token** | 执行记录中的 Token 用量；输入、输出和缓存用量取决于编程工具能提供哪些数据。 |
| **运行时长** | 已开始且已结束的执行时长汇总，按结束时间归入日期，不是人工工时。 |
| **task 数** | 已开始且已结束的执行次数，包括完成、失败和取消，同时展示其中的失败数量。 |

趋势图可以切换费用、Token、运行时长和 task 数。下方排行榜按智能体汇总，可以按不同指标排序；需要具体原因时，回到对应任务的[执行记录](/tasks)查看。

统计反映 Multica 收到的执行与用量记录。没有记录、提供商没有上报某项数据和某项用量确实为零是不同情况，不能只凭一个数字判断智能体是否工作过。

## 查看错误

**错误**页展示失败 task 数、失败率、受影响智能体、错误趋势和失败构成。错误分类包括认证、限流、超时、模型服务、运行时、智能体及其他错误；展开错误码可以进一步定位。

错误统计按执行结束时间汇总成功与失败记录；启动前就失败的执行也会计入，取消的执行不进入错误率分母。因此，它与用量页的 task 数可能不同。

智能体错误榜可按**失败数**或**失败率**排序。运行样本较少时会显示提示，例如只运行一次且失败时，失败率虽是 100%，但不足以说明长期稳定性。

排查时先看错误码和对应执行日志：认证错误检查工具登录和凭据，运行时错误检查守护进程，模型服务或限流错误检查服务可达性与额度。具体处理见[故障排查](/troubleshooting)。统计页不会代替重试、取消或重新分配操作。

## 费用与自定义价格

提供商已上报金额时，Multica 使用该金额；其余记录按模型价格和 Token 数估算。因此，页面合计可能同时包含上报金额与估算金额，不是用于结算的完整账单。

费用为 `$0` 不一定代表免费。模型缺少价格时，其 Token 仍可能有记录，但无法计算对应估算金额。打开**运行时**中的用量区域，按缺少价格的提示设置**自定义价格**；价格变更也会影响统计页的估算部分。

自定义价格保存在当前客户端，不按工作空间隔离，也不会替换提供商已上报的金额。不同客户端配置不同价格时，估算结果可能不同。核对实际支出时，以提供商或内部计费系统的账单为准。

## 可见性与不同页面的口径

工作空间成员可以查看该空间的汇总指标。智能体明细仍遵循访问权限；无权查看的智能体会合并为**其他智能体**，不会因此开放其详情、配置或执行权限。

**全部项目**覆盖整个工作空间；选定项目后，只看该项目的统计。运行时详情的用量则按运行时查看，还可按智能体或模型拆分，范围与工作空间统计不同。比较前先对齐对象、日期、时区与价格配置。

数据尚未加载或刷新未完成时，先等待或点击**刷新**，不把空图直接当成零消耗。费用、Token、执行次数和错误数使用不同的记录来源，定位具体差异时应查看相应 task 的日志与用量。
