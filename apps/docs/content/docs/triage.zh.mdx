---
title: 分拣台
description: 通过手动投递和 CSV 导入收集待分拣任务，审核后再纳入项目、迭代和智能体执行。
---

分拣台用于先收集、再决定是否开展的工作，例如需求建议、缺陷反馈和外部清单。接受之后，任务才进入正式工作范围。

只有主动投递到分拣台的任务需要审核。在普通任务页或项目里新建任务，仍按原有流程处理。

## 打开和设置分拣台

1. 进入目标工作空间，点击侧边栏中的"分拣台"。
2. 如果没有这个入口，打开"设置 → 分拣台"，检查"启用分拣台"。
3. 工作空间的 `owner` 或 `admin` 修改设置后，点击"保存设置"。

新工作空间默认启用分拣台，默认接受后的状态为 `todo`。已经保存过的关闭设置会保留。

| 设置 | 作用 |
| --- | --- |
| 接受后的状态 | 设置接受弹窗的默认值；可选 `backlog`、`todo` 及这两个分类下的自定义状态。 |
| 接受时必须指定优先级 | 开启后，必须选择低、中、高或紧急才能接受。 |
| 分拣责任：不指定 | 不自动指定分拣责任人。 |
| 分拣责任：通知指定成员 | 通知所选成员有新任务待处理，不把该成员设为分拣责任人。 |
| 分拣责任：指定分拣责任人 | 为新投递任务指定责任人，并发送通知。 |

分拣责任设置不会批量改写已有任务；重新审核时会按当时的设置重新确定责任人。分拣责任人负责跟进审核，执行负责人负责后续工作，两者相互独立。

仍有未决任务时不能关闭分拣台，"稍后处理"中的任务也算未决。关闭后，已有审核历史和正式任务保留。

### 谁可以操作

- 当前工作空间的 `owner`、`admin` 和 `member` 都可以人工审核和导入 CSV。
- 只有 `owner` 和 `admin` 可以修改分拣台设置。
- 指定责任人表示工作分工，其他成员仍可审核这条任务。
- 智能体具备创建任务的权限时可以投递，但不能代替成员审核、导入 CSV 或修改设置。

## 手动投递任务

1. 在分拣台点击"创建待分拣任务"。
2. 填写标题，补充背景、预期结果和必要附件。
3. 按需要选择候选项目、候选执行负责人、优先级、标签和日期。
4. 点击"创建待分拣任务"，等待提交完成。

| 字段 | 填写说明 |
| --- | --- |
| 标题 | 必填，最多 500 个字符。 |
| 描述 | 可选，最多 1 MiB；较大的材料可用附件提供。 |
| 候选项目 | 选择已有项目，接受时再确认正式归属。 |
| 候选执行负责人 | 可建议成员、智能体或 AI小队，接受时还会检查是否可分配。 |
| 优先级、标签 | 可提前分类；标签从工作空间已有标签中选择。 |
| 开始日期、截止日期 | 可分别留空；同时填写时，开始日期不能晚于截止日期。 |
| 原始链接 | 可选，填写有效的 HTTP 或 HTTPS 链接。 |

投递后任务已有编号，可以打开详情、补充评论和附件。此时显示"待分拣"，任务状态为 `backlog`；候选项目和候选执行负责人尚未成为正式关联。

待分拣记录不会进入普通任务列表、项目任务统计或迭代。描述和评论中的 @提及不会启动智能体，接受后也不会补跑待分拣期间的提及。

## 在队列中审核

| 页面 | 显示内容 |
| --- | --- |
| 可处理 | 尚未安排稍后处理，或已经到达恢复时间的待分拣任务。 |
| 全部未决 | 所有待分拣任务，包含稍后处理的任务。 |
| 稍后处理 | 已设置恢复时间、尚未到期的任务。 |
| 审核历史 | 历次处理记录和 CSV 导入记录。 |

侧边栏数字表示"可处理"数量。可以按标题或编号搜索，也可以按来源、优先级、候选项目、标签、分拣责任人、提交者和进入时间筛选，并调整排序。

选择一条任务后，在详情中检查内容、来源和候选字段，再使用底部的处理按钮。

| 操作 | 结果与要求 |
| --- | --- |
| 接受 | 确认字段并纳入正式工作，保留原编号、评论和附件。 |
| 拒绝 | 填写 1–2,000 个字符的原因；记录保留，任务状态变为 `cancelled`。 |
| 标记重复 | 选择本工作空间中的正式任务作为重复目标，任务状态变为 `cancelled`。 |
| 稍后处理 | 选择未来 90 天内的恢复时间，任务仍保持待分拣。 |
| 恢复到可处理队列 | 取消稍后处理安排，立即回到可处理队列。 |

"标记重复"支持按标题、任务编号或任务链接查找目标，也可以选择已经结束的正式任务。当前记录的评论和附件保留在原处，不会合并到目标任务；目标以后被删除，仍保留处理时的编号引用。

"稍后处理"提供"一小时后"、"明天上午"、"下周一"和"自定义时间"。确认前查看弹窗中的时区和具体时间；到期后任务自动重新进入可处理范围。

### 重新审核和历史

在"审核历史"中打开已拒绝或已标记重复的记录，点击"重新审核"并填写原因。分拣台必须处于启用状态；任务会回到待分拣，开始新一轮审核，之前的处理记录仍保留。

已接受的任务不能通过"重新审核"退回分拣台，后续调整在正式任务中完成。

审核历史可按处理结果、处理人、处理时间和来源筛选；打开单条任务的"审核历史"可查看原因和字段变化。

### 批量处理

1. 在队列中勾选要处理的任务，点击"批量处理已选任务"。
2. 选择"接受"、"拒绝"、"稍后处理"或"指定分拣责任人"，填写所需信息。
3. 点击"预检"，核对可处理项，再点击"确认处理已选有效任务"。
4. 检查逐条结果；需要时使用"重试未成功项"。

每条任务独立提交，部分失败不会撤销已成功的处理。批量接受沿用各条任务的候选字段和工作空间的默认接受状态，不提供"接受并执行"。

## 接受、项目、迭代和执行

### 接受为正式任务

点击"接受"后，可以在弹窗中调整接受后的状态、优先级、项目、执行负责人、标签和日期，再确认提交。

普通接受只保存审核结果和字段，即使执行负责人是智能体或 AI小队，也不会启动执行。没有选择执行负责人时，也不会自动继承项目配置的 AI小队。

如果工作空间已启用迭代，且服务器支持接受时分配，弹窗会显示迭代选择。可以同时加入"计划中"或"进行中"的迭代；不选则保持"无迭代"。接受和加入迭代一起提交，目标失效时需要重新选择。

接受后可在[任务](/issues)、对应[项目](/projects)或所选[迭代](/iterations)中继续安排工作。

### 接受并执行

1. 打开"接受"旁的下拉菜单，选择"接受并执行"。
2. 明确选择智能体或 AI小队作为执行负责人；AI小队由其负责人接收执行。
3. 检查"执行确认"中的执行者、运行时和项目资源，处理权限或环境提示。
4. 点击"接受并执行"确认。

能看到候选智能体不代表有调用权限；接受时保存智能体或 AI小队分配也会检查权限。立即执行还要求运行时和项目资源可用，具体规则见[分配任务给智能体](/assigning-issues)。

如果显示"已接受，但执行尚未启动"，审核结果仍然有效。原发起人在仍有权限时可以点击"重试执行"；如果负责人、运行时或项目资源等执行上下文已改变，需要在正式任务中重新确认执行。

## 从 CSV 导入

### 准备文件

点击"导入 CSV → 下载 CSV 模板"，替换示例行。第一行是列名，之后每行是一条待分拣任务，只有标题必填。

- 文件最大 5 MiB，最多 1,000 行数据，不含表头；转换为 UTF-8 后的内容也需满足大小限制。
- 推荐用 Excel/WPS 另存为 "CSV UTF-8"；也支持 GBK/GB18030 和带编码标记（BOM）的 UTF-16。
- 列名不能为空或重复，可用中文或英文；上传后还能调整映射。

| 模板列名 | 填写规则 |
| --- | --- |
| 标题 / `title` | 必填，最多 500 个字符。 |
| 描述 / `description` | 可换行，最多 1 MiB；保留 CSV 的引号转义。 |
| 优先级 / `priority` | 紧急、高、中、低、无优先级，或 `urgent`、`high`、`medium`、`low`、`none`；留空表示未指定。 |
| 标签 / `labels` | 已有标签名称，多个标签建议用英文分号 `;` 分隔。 |
| 项目 / `project` | 已有项目名称，导入为候选项目。 |
| 负责人 / `assignee` | 成员邮箱或可见智能体的名称，导入为候选执行负责人。 |
| 开始日期 / `start_date` | `YYYY-MM-DD`。 |
| 截止日期 / `due_date` | `YYYY-MM-DD`，不能早于开始日期。 |
| 原始链接 / `source_url` | HTTP 或 HTTPS 链接。 |
| 外部编号 / `external_id` | 来源清单中的编号，最多 1,000 个 UTF-8 字节，用于检查重复导入。 |

项目和标签按名称匹配，成员按邮箱匹配，智能体按名称匹配。找不到唯一可用对象时会提示警告，相关字段留空，不会自动创建项目、标签或负责人。状态、迭代和附件列不会导入。

### 映射、预览、确认

1. 点击"选择 CSV 文件"上传文件。此时只生成预览，不创建任务。
2. 在"映射列"中，为每列选择字段或"忽略"。同一目标字段只映射一列；修改后点击"应用映射"重新预览。
3. 检查有效行、警告行、错误行和重复行。可以点击"选择有效且不重复的行"，再逐条取消不需要的行。
4. 阅读每行警告；保留勾选表示确认按预览结果导入。错误行无法导入。
5. 外部编号在文件内重复，或已在本工作空间导入过时，默认跳过。确实需要另一条记录时，逐行勾选"仍要导入此重复行"。相似标题只作提示，不会自动合并。
6. 点击"导入已选行"，处理期间保持窗口打开，再核对已创建、跳过和失败的数量。

导入成功的行仍是待分拣任务，需要继续审核；不会直接成为正式任务或启动智能体。

### 处理失败和继续导入

导入按行提交，部分失败时已经创建的任务会保留。修复临时问题后，可在同一批次使用"重试未成功项"；成功行不会重复创建。

内容有误时，点击"下载失败行"，根据原始列、来源行号和错误说明修改文件，再上传生成新预览。保留外部编号有助于检查跨批次重复。

在"审核历史"中点击对应的 CSV 导入记录，可打开批次详情。批次明细、继续导入和失败文件仅供原导入者在仍属于该工作空间时访问。

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 侧边栏没有分拣台 | 检查工作空间是否正确，再到"设置 → 分拣台"确认启用状态；若提示服务器不支持，需要管理员升级服务器。 |
| 找不到刚投递的任务 | 在分拣台的"全部未决"中查找并清除筛选；尚未接受的任务不在普通任务列表中。 |
| 可处理数量为 0，却无法关闭 | 检查"稍后处理"，其中的记录也必须先处理完。 |
| 接受时提示缺少优先级 | 在接受弹窗选择低、中、高或紧急，再提交。 |
| 提示任务已被修改 | 点击"刷新当前任务"，核对最新内容，再提交新的处理决定；原输入会保留。 |
| 分拣责任人已离开工作空间 | 在待分拣任务上点击责任人，重新指定当前成员。 |
| CSV 显示乱码或编码错误 | 从原始文件重新另存为 "CSV UTF-8"；超过大小或行数限制时拆分文件。 |
| CSV 中的项目或负责人没关联 | 检查名称、成员邮箱、访问权限和同名对象，修正后重新预览，或在接受时重新选择。 |
