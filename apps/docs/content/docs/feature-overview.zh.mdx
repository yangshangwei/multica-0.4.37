Multica 有两个工作范围：**工作空间**用于团队内的任务、资源和配置；**协作空间**用于你参与的跨工作空间任务。共享一条协作任务不会让参与者自动加入来源工作空间。

## 工作管理

| 功能 | 从哪里进入 | 可以做什么 |
| --- | --- | --- |
| [任务](/issues) | 侧边栏“任务”“我的任务” | 创建和分配任务，管理状态、优先级、子任务和自定义属性；切换视图、筛选和批量操作 |
| [项目](/projects) | 侧边栏“项目” | 组织目标、任务和进度，配置负责人、日期与 AI小队 |
| [项目资源](/project-resources) | 项目详情 | 提供仓库、本地目录和说明，供智能体执行时使用 |
| [分拣台](/triage) | 启用后的“分拣台” | 接收需求、审核、延后、拒绝或接纳；支持 CSV 导入 |
| [迭代](/iterations) | 启用后的“迭代” | 安排一期工作、记录范围变化、查看进展并处理未完成任务 |
| [评论](/comments) | 任务详情 | 回复、提及、表情、解决讨论，以及从评论创建子任务 |

“我的任务”可按分配给我、我创建的和我参与的范围查看工作。项目、迭代和视图组织的是已有任务；移动或筛选不会创建另一份任务。分拣台和迭代需要工作空间启用对应功能，权限与操作条件见各自指南。

## 人与 AI 协作

| 功能 | 从哪里进入 | 使用说明 |
| --- | --- | --- |
| [智能体](/agents) | 侧边栏“智能体” | 查看可运行的智能体，了解访问范围、自治等级和审批边界 |
| [创建和配置智能体](/agents-create) | 智能体页的创建入口及智能体详情 | 从模板或其他起点创建，配置指令、模型、skill、运行时和工具 |
| [AI小队](/squads) | 侧边栏“AI小队” | 通过队长协调成员，将模板用于项目并检查派发与交付结果 |
| [触发执行](/triggering-agents) | 分配、评论提及、对话或自动化 | 区分“任务归谁负责”和“请谁处理这一条输入” |
| [对话](/chat) | 侧边栏“聊天” | 与 AI 沟通、提供项目上下文，查看和停止执行 |
| [快捷操作](/issues#快捷操作) | 设置中的“快捷操作”、普通任务详情右侧 | 保存常用执行者和提示词，点击执行，或在评论中用 `/` 填入后修改 |
| [审批](/agents#高风险动作必须由人审批) | 智能体页的“审批” | 审阅计划，按权限批准、驳回或查看结果；批准本身不执行命令 |
| [自动化](/autopilots) | 侧边栏“自动化” | 配置定时或 Webhook 触发，查看运行与投递记录 |

智能体执行是否可用还取决于 Access、运行时在线状态及具体工具的支持范围。执行结束、任务完成、交付被验收是不同结果，分别看[执行记录](/tasks)和任务状态。

## 跨工作空间协作

从全局导航切换到**协作空间**，查看“当前处理”和“我参与的”，或创建协作任务。

- [协作空间](/collaboration)：从创建、转交和补充信息，到 AI 资源授权、执行、提交结果与验收。
- [协作上下文与知识](/collaboration-knowledge)：维护跨轮次上下文、查看版本，将可复用结论提交给项目或工作空间审核。

这里的参与权限、AI 资源授权和通知有独立规则。仅复制链接、提供资源或添加参与者，都不等于授予整个工作空间的访问权。

## 能力与运行环境

| 功能 | 从哪里进入 | 使用说明 |
| --- | --- | --- |
| [Skill](/skills) | 侧边栏“Skill” | 管理可复用指令和资料，导入、编辑并绑定给智能体 |
| [MCP](/mcp) | 侧边栏“MCP”或设置中的 MCP | 保存工作空间工具配置，再显式分配给智能体 |
| [能力市场](/mcp) | 侧边栏“能力市场” | 浏览 MCP 与 Skill 资源，按引导保存或使用 |
| [运行时](/daemon-runtimes) | 侧边栏“运行时” | 查看执行电脑、在线状态、并发和自定义配置 |
| [AI 编程工具](/install-agent-runtime) | 运行时所在电脑 | 准备工具和登录，确认守护进程能发现它 |
| [工具支持范围](/providers) | 配置模型、MCP 或恢复会话前 | 核对当前 provider 的能力差异 |
| [统计与用量](/usage) | 侧边栏“统计” | 按时间和项目查看消耗、运行时长和错误，定位异常 |
| [代码仓库集成](/vcs-integration) | 设置中的仓库与集成 | 连接管理员提供的 Git 服务，跟踪关联 PR / MR |

保存配置不等于已经在执行电脑上安装对应程序。内网服务地址、安装包和必要依赖由管理员提供。

## 通知、个人偏好和管理

- **收件箱**：查看工作空间任务动态，设置已读、归档和订阅，见[收件箱与订阅](/inbox)。协作任务还有协作空间自己的通知入口。
- **个人设置**：在“设置”中管理个人资料、偏好设置、通知、快捷键和[个人访问令牌](/auth-tokens)。这些偏好与工作空间的共享配置不同。
- **工作空间设置**：管理名称、上下文、[成员与权限](/members-roles)、标签、任务状态和自定义属性；具体操作取决于角色。
- **平台管理后台**：面向管理员管理账号、安装、运行时、告警和审计，见[平台管理](/platform-administration)。工作空间管理员不等于平台超级管理员。
- **可选入口**：插件、计费等设置受部署开关控制；只有部署启用并完成配置后才会显示。某个集成入口可见，也不代表该服务在内网可达。

## 客户端、文档与排查

[桌面应用](/desktop-app)提供工作空间标签页、账号协作入口和内置守护进程；[CLI](/cli)提供终端操作。Web 与 Desktop 连接同一服务和账号时共享对应数据，平台专属操作以各自指南为准。

帮助菜单提供“使用文档”“变更说明”和“意见反馈”。使用文档由当前服务器提供；桌面版本与服务器版本可以不同。功能缺失或执行失败时，先检查权限、功能配置和运行时，再按[故障排查](/troubleshooting)定位。
