# SDLC to ADLC Leap Implementation Plan

**Goal:** Implement the approved line-to-network transition, introduced by an S-to-A letter change, while preserving the existing final diagram.

**Architecture:** Keep animation lifecycle local to DevelopmentLifecycle and geometry in shared UI CSS. A single 3.2-second CSS timeline controls the heading, nodes, connections and signals. React tracks whether playback is active and a replay key; the final feedback animation completes playback. No new dependencies, global state or platform APIs.

**Tech Stack:** React, TypeScript, CSS/SVG, existing Button/Lucide components, Vitest, Chromium.

## Approved motion
- 0–640 ms: neutral SDLC flow and a sequential signal establish the starting point.
- 512–960 ms: S leaves its clipped letter slot and blue A replaces it; DLC remains fixed.
- 960–1984 ms: the row gathers briefly and unfolds into the existing collaboration graph; context and branches connect.
- 1984–2560 ms: one signal splits into coding, testing and review paths, then converges on human delivery.
- 2624–3200 ms: the feedback path draws and carries the signal back to the goal; all animation stops.
- The final layout, human decision content, theme tokens and onboarding flow remain intact. Reduced motion renders the final state immediately. A localized replay button is usable with a keyboard and does not remount the questionnaire.

## Implementation decisions
- Completion follows the final feedback signal, not the earlier node transition.
- `focusableWhenDisabled` preserves Chromium keyboard focus during replay; `aria-disabled` communicates the active state and a handler guard prevents repeated activation.
- The reduced-motion media listener is removed on unmount. No timers or long-running animation loops are introduced.
- Reused path definitions keep visible connectors and traveling signals aligned.
