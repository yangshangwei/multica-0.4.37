# 协作详情工具栏与资料抽屉

按已选方案一实现：任务摘要下方显示紧凑的图标文字工具栏，任务信息、附件、协作上下文、知识候选、子任务、操作记录统一在右侧抽屉查看。原正文底部折叠列表已移除。

## 样式与交互

- 延续现有字体、灰阶、语义色和按钮体系；主操作保持最高强调，资料入口使用轻量样式。
- 抽屉宽度上限 44rem，小窗口占满可用宽度；固定标题、任务名称和分类导航，正文独立滚动。
- 分类切换、关闭重开保留同一面板实例，未保存的上下文/知识草稿和上传流程不被卸载。
- 附件数量来自成功查询，子任务只显示投影总数；知识没有全量计数，未知数量不显示成零。
- 错误和待恢复操作在工具栏显示“需要查看”，点击直接进入对应面板。
- 文件参考链接、重复上下文通知可打开正确面板。跳往任务要求、评论或运行记录时，先关闭抽屉及内部预览，再定位主内容。

## 修改范围与简化

新增 detail-auxiliary.tsx 统一容器和 panel-status.ts 展示状态契约，删除 CollaborationDetail 原底部 disclosure 拼装。既有附件、上下文、知识、活动面板只增加可选状态/可见性参数；没有复制服务端实体、没有新增 store/依赖，也未改变业务请求协议。

独立检查修复了文件预览在父抽屉隐藏后仍留在屏幕上，以及操作记录读取错误没有入口提醒两个问题。隐藏面板使用 hidden/inert，嵌套预览使用 active 门控；关闭时不把焦点返回隐藏控件。

- Views TypeScript、变更代码 ESLint、git diff --check 通过。

- 原生 Electron 当前源码检查：宽/窄窗口、独立滚动、Esc/焦点返回、上下文草稿切换和关闭保留、附件嵌套预览、重复通知定位、主锚点关闭浮层和放大字号；具体结果在 checks.json。
- 既有 E2E 发现入口与任务信息定位已同步，生产 Web/完整端到端链本轮未重跑，仅收集检查通过。
