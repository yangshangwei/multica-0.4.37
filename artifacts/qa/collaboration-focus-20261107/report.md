# 协作详情聚焦与弹框优化

已完成本次 impeccable 审计确定的改动。

## 改动与问题闭环

| 问题 | 处理 |
| --- | --- |
| 工作流输入在按钮下展开，推动正文 | 提交结果、转交、补充信息、编辑等复用可滚动弹框；More 改为弹出菜单 |
| 角色权限、来源字段与主线争夺注意力 | 保留简短角色，将完整权限放进参与者展开内容；来源/字段与辅助资料集中在正文下方收起 |
| 评论区默认展示全部提及对象和上传表单 | 提及和附件改为工具按钮；待上传/已选文件主动展开，组件保持挂载 |
| 弹框可能遮挡原请求恢复 | 错误、等待和原始请求查询随表单进入弹框；关闭后仍可恢复 |
| 上传锁禁用取消上传 | 分离上传期间的关闭锁与表单写入锁，取消上传仍可操作 |
| 未知回执使原按钮禁用，关闭后焦点无处返回 | 优先返回原按钮；按钮不可用时返回查询原结果控件 |
| 来源任务已有弹框 | 通过 embedded 模式复用现有容器，不叠加第二个弹框 |

主线为“任务要求 → 交付结果/验收 → 讨论”。未变更服务端业务规则、权限、结果版本和幂等恢复协议；没有新增依赖。
